> 基于3位教授两轮审阅+用户反馈修订
> 日期：2026-07-01
> v5 修订：消融重新编号+命名；参数敏感性独立为先导实验；S3 从 τ 改为 γ（与创新点直接相关）；主实验+消融在最优参数上做

---

## 实验执行顺序

```
Step 1: 参数敏感性实验（先导） → 确定最优参数组合
Step 2: 主实验（在最优参数上） → 已完成（当前结果）
Step 3: 消融实验（在最优参数上） → 验证各组件贡献
```

**为什么参数敏感性先做**：消融实验应在最优参数组合上进行，否则消融结果可能被"参数未调好"混淆。先确定最优 K/α/τ，再在该配置上跑消融，因果更干净。

## 1. 参数敏感性实验（先导，3 个参数）

> 设置：NYC→CHI（跨城），patience=10
> 目的：确定最优参数组合，为消融实验提供基础配置

### S1: K（原型数）— STCross_K

| 维度 | 内容 |
|------|------|
| **搜索值** | 1, 2, 4, 8, 16 |
| **默认值** | 8 |
| **验证** | DIP：原型库覆盖能力 |
| **说明** | K=1 为退化基线——单原型时 softmax(-dist) 恒为 1，Z_a 不影响输出，退化为"学习一个全局常数 pattern"，比 FC 更受限 |
| **预期** | K太小→异常模式不够区分；K太大→原型坍塌/冗余。存在最优 K |
| **证伪条件** | 若 K=1 与 K=8 无显著差异，原型非必要 |

### S2: α（L_cap 权重）— STCross_alpha

| 维度 | 内容 |
|------|------|
| **搜索值** | 0, 0.001, 0.01, 0.05, 0.1 |
| **默认值** | 0.01 |
| **验证** | DIP+DDAC：容量约束强度（IB λ 参数） |
| **说明** | α=0 为完全无约束边界——Z_a 退化为标准 VAE 编码器，无容量压缩。α=0.1 可能 posterior collapse |
| **预期** | 存在拐点：α过小→城市信息残留；α过大→posterior collapse。最优在中间 |
| **证伪条件** | 若 α=0 与 α=0.01 无差异，IB 非迁移来源 |

### S3: γ（L_proto 权重）— STCross_gamma

| 维度 | 内容 |
|------|------|
| **搜索值** | 0.01, 0.1, 0.5, 1.0 |
| **默认值** | 0.1 |
| **验证** | DIP：原型判别性强度（triplet margin 权重） |
| **说明** | γ 控制 L_proto = max(0, d(Z_a, P_pos) - d(Z_a, P_neg) + margin) 的权重。确保不同异常类型的原型在 latent 空间中可区分。γ 太小→原型坍塌混在一起；γ 太大→过度约束，挤压 L_pred |
| **预期** | γ=0.1 最优。triplet margin 已有 margin=0.5 硬间隔，γ 只控制损失权重——适中即可 |
| **证伪条件** | 若 γ=0.01 与 γ=0.1 无显著差异，原型判别性约束非必要 |
| **公式** | L_proto = max(0, dist(Z_a, P_pos) - dist(Z_a, P_neg) + 0.5); L += γ · L_proto |
| **类比** | γ = 文件柜整理纪律。γ=0 → 文件随便塞，"节假日"文件夹混着天气文档；γ=0.1 → 适度分类，文件夹清晰；γ=1.0 → 花全天整理不读文档 |

### 工程预备（参数敏感性执行前提）

- **`VariationalLSTM.forward` 加 `logvar = logvar.clamp(-8, 4)`**（防止高 α 时 NaN）
- S2 的 α=0.1 额外保存 Z_a 方差（σ_a 分布），检测 posterior collapse

### 三个参数与创新点的对应关系

| 参数 | 控制模块 | 控制效果 | 创新点 | 类比 |
|------|---------|---------|--------|------|
| **S1 K** | APB | 原型分辨率——能区分多少种异常 | **DIP** | 调色盘的颜色数 |
| **S2 α** | AEnc | 容量压缩——Z_a 被压向 N(0,1) 的力度 | **DIP+DDAC** | 笔记本的页数限制 |
| **S3 γ** | APB | 原型判别性——不同类型推多开 | **DIP** | 文件柜整理纪律 |

### 理论预期最优组合

| 参数 | 预期最优 | 理由 |
|------|---------|------|
| **K=8** | 与交通异常自然类型数匹配（节假日~3种 + 天气~3种 + 正常~2种） | K<4 不够区分；K>8 冗余 |
| **α=0.01** | 偏差空间下 IB 只需轻度压缩（NBL+归一化已预消除大部分城市信息） | 偏差空间最优 α < 绝对值空间最优 α |
| **γ=0.1** | triplet margin 已有 0.5 硬间隔，γ 适中即可 | γ 过大挤压 L_pred，过小原型坍塌 |

**可检验的理论预测**：
- K 曲线在 K=8 处有峰值（与自然类型数匹配）
- α 曲线在 α=0.01 处有拐点（偏差空间 IB sweet spot）
- γ 曲线在 γ=0.1 处最优（适中判别性）
- K×α 交互：K=16+α=0.001 时性能最差（原型多+无约束→过拟合城市特定模式）

## 2. 消融实验（在最优参数上，4 个变体）

> 设置：NYC→NYC（同城）+ NYC→CHI（跨城），patience=10
> **在 S1-S3 确定的最优参数组合上运行**
> 每个变体只改一个维度，附证伪条件

### STCross_w/o DevSpace（A1: 绝对值空间+原型）

| 维度 | 内容 |
|------|------|
| **改动** | AEnc 直接吃 X（绝对值），不做 Δ=X-NBL，不做方差归一化，alpha=0（L_cap关闭）。APB 原型在绝对值空间学习。Ŷ = Δ̂_type + Δ̂_adj |
| **保留** | APB ✅、CEnc+CAD ✅、MIC ✅ |
| **验证** | DIP 子贡献①：偏差空间的必要性 |
| **叙事** | "空间切换"——NBL+归一化+L_cap 的关闭是空间切换的必然伴随 |
| **证伪条件** | 若跨城衰减<5%，偏差空间非迁移来源 |

### STCross_w/o ProtoBank（A2: 偏差空间+无原型）

| 维度 | 内容 |
|------|------|
| **改动** | 保留 NBL+归一化+L_cap。去掉 APB，Z_a 直接经 FC 预测 Δ̂_type。L_proto/L_ent 代码层 if 跳过。Ŷ = NBL + FC(Z_a) + Δ̂_adj |
| **保留** | NBL ✅、归一化 ✅、L_cap ✅、CEnc+CAD ✅、MIC ✅ |
| **验证** | DIP 子贡献②：原型匹配的必要性 |
| **证伪条件** | 若跨城 MAE 下降<3%，原型非必要 |

### STCross_w/o CityBranch（A3: 去掉城市调整分支）

| 维度 | 内容 |
|------|------|
| **改动** | 去掉整个 Z_s 分支（CEnc+CAD+MIC）。Ŷ = NBL + Δ̂_type |
| **保留** | NBL ✅、归一化 ✅、L_cap ✅、AEnc ✅、APB ✅ |
| **验证** | DDAC 城市调整分支整体：城市自适应的边际贡献 |
| **叙事** | A3 测试城市分支整体必要性，三层中第3层(MIC)的单独贡献由 A4 验证 |
| **证伪条件** | 若跨城 anomaly MAE 不显著上升（<3%），城市调整非必要 |

### STCross_w/o MIC（A4: 保留城市分支，仅关 MIC）

| 维度 | 内容 |
|------|------|
| **改动** | 保留 CEnc+CAD（Z_s 分支仍在），但 beta=0（去掉 MIC 互信息约束）。MIC 估计器保留实例化但 forward bypass |
| **保留** | NBL ✅、归一化 ✅、L_cap ✅、AEnc ✅、APB ✅、CEnc+CAD ✅ |
| **验证** | DDAC 第3层（冗余级）：MIC 分支正交的边际贡献 |
| **证伪条件** | 若性能不降（MAE 差异<2%），MIC 非必要 |

### MIC 是什么？为什么单独消融？

**MIC（Mutual Information Constraint）** 是 DDAC 三层解耦的第3层——冗余级。

**作用**：最小化 I(Z_s; Z_a)，确保两个分支不重复信息。

**为什么需要**：
- 没有 MIC：Z_s 可能"偷懒"——重复 Z_a 已捕获的异常类型信息，不去学城市特定表征
- 有 MIC：Z_s 被迫学 Z_a 没有的信息（城市特定形态），分工明确

**为什么单独消融**：
- A3 把 CEnc+CAD+MIC 整体关掉，无法区分"是 CAD 城市调整的功劳还是 MIC 分工约束的功劳"
- A4 保留 CEnc+CAD（城市调整仍在），只关 MIC（分工约束去掉），直接回答"MIC 这个第3层是否有边际贡献"

**实现**：两阶段优化——阶段1训练 MIC 估计器估计互信息上界（每3步更新1次），阶段2最小化互信息。A4 中 beta=0，MIC 估计器不参与训练和推理。

### 实现细节

**STCross_w/o DevSpace**：
- `_net_forward`：`delta = X`；`delta_norm = delta`（跳过归一化）；`y_pred = delta_type + delta_adj`
- `_compute_loss`：alpha=0，跳过 L_cap
- warmup=5，patience=15

**STCross_w/o ProtoBank**：
- `__init__`：`use_proto=False`，实例化 `self.fc_direct = nn.Linear(latent_dim, P)`
- `_net_forward`：`if use_proto: ... else: delta_type = self.fc_direct(z_a); w=None; dist=None`
- `_compute_loss`：`if use_proto: l_proto = ... else: l_proto = 0.0`（代码层跳过）

**STCross_w/o CityBranch**：
- `__init__`：`use_city_branch=False`，CEnc/CAD/MIC 保留实例化但 bypass
- `_net_forward`：`if use_city_branch: z_s=...; delta_adj=... else: delta_adj = 0`
- `_compute_loss`：`if use_city_branch: l_mic=...; l_adj=... else: l_mic=0; l_adj=0`
- `fit`：MIC 更新加 `if use_city_branch and beta > 0:` 守护

**STCross_w/o MIC**：
- `__init__`：beta=0
- `_compute_loss`：`if beta > 0: l_mic = self.mic(...)` else `l_mic = 0.0`
- `fit`：MIC 更新加 `if beta > 0:` 守护
