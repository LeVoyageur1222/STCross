# ST01: How to Break It Down for Building It Up? Theory-Guided Graph Decomposition Learning for Spatiotemporal Traffic Prediction

## 基本信息
- **会议/期刊**: IEEE Transactions on Pattern Analysis and Machine Intelligence (TPAMI)
- **年份**: 2026 (Vol. 48, No. 5, May 2026)
- **作者**: Jiahao Ji, Jingyuan Wang (通讯作者), Yu Mou, Cheng Long, Junjie Wu（北京航空航天大学 & 南洋理工大学）
- **关键词**: 分解预测 (Decompose-then-Predict)、Fano不等式、数据诱导误差 (Data-induced Error)、理论引导模型设计、图分解学习、时空交通预测
- **代码**: https://github.com/bigscity/TGDL

## 研究问题与动机

### 核心问题
主流时空交通预测模型假设所有地理单元在不同条件下具有**统一的时空相关性**，使用共享参数对所有场景进行预测。这种简化忽略了人类出行模式的复杂性和异质性，导致次优预测。

### "先分解再预测"(DTP)范式的理论空白
近年来"decompose-then-predict"方法在实践中取得了良好效果，但存在两个未解决的根本性问题：
- **Q1**: 什么类型的分解能从理论上保证分解后的子成分比原始数据更具可预测性？
- **Q2**: 能否设计一个有理论指导的、可移植到各种交通预测模型的分解框架？

### 重要性
- 现有DTP方法大多依赖启发式或特定领域的分解策略（如趋势-季节分解、小波分解），缺乏形式化的有效性保证
- 这些方法通常与特定任务或架构紧耦合，限制了通用性和可移植性
- 需要信息论层面的理论分析来指导分解算法的设计

## 核心贡献

1. **首次为分解预测范式提供理论基础**：基于信息论分析，推导出分解算法能降低预测误差的充分条件，建立了"分解后预测"范式的理论根基
2. **提出组件独立性原则 (Component Independence Principle, CI)**：证明如果分解后的组件相互独立，则每个子问题的数据诱导误差率严格低于原始问题
3. **提出TGDL框架**：理论引导的图分解学习框架，将图结构时空数据分解为近似独立的子图组件，包含结构分解和信号分解两大模块
4. **可插拔式设计**：TGDL可作为插件集成到任何基于图的交通预测模型中，平均提升性能 **19.37%**
5. **广泛的实验验证**：在4个公开数据集上验证了理论分析和框架的有效性

## 方法概述

### 整体架构

```

│                  TGDL Framework                      │
│                                                      │
│  Original Traffic Graph G(g) = (V, A(g))            │

│           ▼                                          │
│  ┌──────────────────────┐                            │
│  │ Structure Decomposition│ ← Structure Indep. Reg   │

│             │                                        │

│  │ Signal Decomposition │ ← Signal Indep. Reg        │
│  │ (Residual Decomp.   │    L_s (MI minimization)   │

│  └──────────┬───────────┘                            │
```

### 三大步骤
1. **图结构分解 (Graph Structure Decomposition)**：通过软掩码矩阵将原始图划分为多个结构独立的子图
2. **图信号分解 (Graph Signal Decomposition)**：通过残差分解流(RDF)迭代提取各子图的独立信号分量
3. **集成交通预测 (Integrated Traffic Prediction)**：每个子图用专属模型预测，结果求和聚合

## 关键技术细节

### 1. 信息论建模：噪声信道类比

将交通预测建模为噪声信道传输过程：

$$Y \xrightarrow{\text{Encoder}} \tilde{X} \xrightarrow{\text{Noisy Channel}} X \xrightarrow{\text{Decoder}} \hat{Y}$$

预测误差来源于两个方面：
- **数据诱导误差 (Data-induced Errors)**：信道噪声导致的信息损失，即 $H(Y|X)$，代表数据集固有的预测难度上限
- **模型诱导误差 (Model-induced Errors)**：解码器能力有限导致的误差，通过参数优化可降低

> **关键洞察**：即使模型诱导误差降为零，数据诱导误差仍然存在，它是数据集本身的特性，不受模型参数影响。因此，降低数据诱导误差是提升预测性能的根本途径。

### 2. Fano不等式与数据诱导误差率

基于Fano不等式建立预测误差率 $e$ 与数据诱导误差熵 $H(Y|X)$ 的关系：

$$H(Y|X) \leq H(e) + e \log(M-1)$$

其中 $S_{\min} = H(Y|X)$，对应的误差率下界 $e_{\min}$ 即为**数据诱导误差率**，仅由数据的内在不确定性决定。

### 3. 组件独立性原则 (CI Principle) — 核心理论贡献

**定理4 (充分条件)**：若分解算法满足以下三个条件，则分解后所有子问题的数据诱导误差值之和严格小于原始问题：
1. $Y_k \perp X_{k'}$，$\forall k' \neq k$（子问题输出与其他子问题输入独立）
2. $Y_k \perp Y_{k'}$，$\forall k' \neq k$（子问题输出之间相互独立）
3. $X_k \perp X_{k'}$，$\forall k' \neq k$（子问题输入之间相互独立）

即：**促进分解组件之间的独立性，是降低预测内在难度的充分条件**。

> 注意：CI原则是充分条件而非必要条件。不满足CI原则的分解在实践中也可能有效，但不在当前理论分析范围内。

### 4. 结构分解模块

使用**软掩码矩阵**实现可微分的图结构分解：

$$A^{(k)} = M^{(k)} \odot A^{(g)}, \quad m_{ij}^{(k)} = \frac{\exp(w_{ij}^{(k)})}{\sum_{k'=1}^{K} \exp(w_{ij}^{(k')})}$$

SoftMax确保 $\sum_{k=1}^{K} a_{ij}^{(k)} = a_{ij}^{(g)}$，满足分解一致性。

**结构独立性正则化**：最小化子图邻接矩阵间的Frobenius内积，鼓励正交分解：

$$\mathcal{L}_a = \frac{1}{K(K-1)} \sum_{k=1}^{K} \sum_{k' \neq k} \| A^{(k)\top} A^{(k')} \|_F^2$$

### 5. 信号分解模块 — 残差分解流 (RDF)

迭代地从残差信号中提取各子图的信号分量：

$$X_t^{(g_k)} = X_t^{(g_{k-1})} - X_t^{(k-1)}, \quad X_t^{(k)} = \text{STBlock}(X_t^{(g_k)}, A^{(k)}, \Theta_b^{(k)})$$

每个ST Block采用编码器-解码器结构：
- **编码器**：$H_t^{(k)} = \text{Encoder}(X_t^{(g_k)}, A^{(k)}, \Theta_e^{(k)})$
- **解码器**：$X_t^{(k)} = \text{Decoder}(H_t^{(k)}, A^{(k)}, \Theta_d^{(k)})$

**信号独立性正则化**：使用CLUB方法估计互信息上界并最小化：

$$\mathcal{L}_s = \frac{1}{K(K-1)} \sum_{k=1}^{K} \sum_{k' \neq k} \widehat{MI}_{UB}(H^{(k')}, H^{(k)})$$

### 6. 训练目标

联合优化四项损失，权重通过动态加权平均(DWA)自适应调整：

$$\mathcal{L} = \gamma_p \mathcal{L}_p + \gamma_a \mathcal{L}_a + \gamma_c \mathcal{L}_c + \gamma_s \mathcal{L}_s$$

- $\mathcal{L}_p$：预测误差损失
- $\mathcal{L}_a$：结构独立性正则化
- $\mathcal{L}_c$：分解一致性损失（子图信号之和等于原始信号）
- $\mathcal{L}_s$：信号独立性正则化

- STGCN, GWNet, MTGNN, MSDR, STSSL

**分解方法对比**（三类）：
- 两阶段分解：PTD-XFMR, EMD-XFMR

### 主要结果

1. **普遍提升**：TGDL在所有base model上均显著提升性能，MAE/RMSE/MAPE平均降低 **19.37%/17.62%/19.49%**
2. **简单模型受益更大**：TGDL对STGCN等轻量级模型的提升幅度大于GWNet等强模型，说明分解降低了任务内在难度
3. **缩小模型间差距**：加入TGDL后，不同base model的性能标准差显著降低
4. **高熵数据集收益更大**：PEMS数据集（模式更复杂、熵更高）的提升远大于NYC数据集，表明**数据复杂度越高，分解的收益越大**
5. **优于所有分解基线**：TGDL在四个数据集上一致优于其他分解方法
6. **消融实验**：每个组件均有贡献；信号分解+独立性正则化的协同效应尤为关键
7. **可扩展性**：增加子图数量带来的性能提升并非仅因参数量增加（同等参数量的堆叠STGCN无类似提升），且训练时间和内存开销几乎不变
8. **最优子图数**：NYCBike=6, NYCTaxi=6, PEMSD4=7, PEMSD8=12

## 与本项目的关联

### 直接相关性
本文研究的交通流量预测与我们构建的**节假日/极端天气异常客流预测系统**高度相关。以下是具体关联点：

1. **异常场景下的数据异质性更强**：节假日和极端天气会导致客流模式发生剧烈变化（通勤模式消失、聚集性出行增加等），数据的条件熵 $H(Y|X)$ 显著升高。论文的实验结论明确指出：**数据复杂度越高，TGDL分解的收益越大**。这意味着我们的异常客流预测场景正是TGDL最能发挥优势的场景。

2. **"分解"思想适用于异常模式分离**：可以将客流数据分解为：
   - **常规通勤分量**：工作日稳定模式
   - **节假日/事件分量**：特殊时段的异常模式
   - **天气影响分量**：极端天气引起的波动
   - **随机扰动分量**：不可预测的噪声
   
   这与TGDL的CI原则一致——让各分量尽可能独立，降低每个子问题的预测难度。

3. **可插拔架构适合工程落地**：TGDL作为插件可以集成到我们已有的任何图神经网络预测模型中，无需从头重新设计模型。

### 可借鉴的思路

1. **理论驱动的分解设计**：不要盲目分解，应以"组件独立性"为指导原则设计分解策略。在我们的场景中，可以先计算不同时段/场景的条件熵，评估分解的潜在收益。
2. **结构分解+信号分解的双重策略**：不仅分解时间序列信号，还分解空间图结构。对于地铁/公交网络，可以将线网分解为功能独立的子网络（如通勤线路vs旅游线路）。
3. **独立性正则化机制**：引入互信息最小化约束，确保分解后的分量真正独立，避免冗余。
4. **残差分解流(RDF)**：逐步从信号中剥离已识别的分量，保证分解的一致性和完整性。
5. **动态加权训练策略(DWA)**：多任务损失权重的自适应调整，避免手动调参。

## 关键启发

1. **📐 理论先行，方法跟进**：本文最大的价值不在于提出了某个具体的模型，而在于先用信息论（Fano不等式）回答了"什么样的分解才有效"这个根本问题，然后据此设计方法。我们在设计异常客流预测系统时，也应先思考"异常"的本质是什么、如何量化异常的预测难度，再选择技术方案。

2. **🎯 数据诱导误差是性能天花板**：模型再复杂也无法突破数据本身的预测难度上限。在异常场景中，应优先关注如何降低数据诱导误差（如通过分解、引入外部变量等），而非一味增大模型容量。论文的结论表明，**在高熵数据上，分解比加模型层数更有效**。

3. **🔌 可插拔框架优于端到端大模型**：TGDL证明了"分治"策略的价值——与其用一个超大模型拟合所有模式，不如将问题分解为更简单的子问题分别求解。这对我们的工程实践意义重大：可以针对不同类型的异常（节假日、天气、突发事件）训练专门的子模型，再通过聚合得到最终预测。

4. **📊 分解前后的诊断工具**：论文中使用条件熵 $H(Y|X)$ 衡量数据集难度、用组件间相关矩阵可视化分解效果、用Silhouette Score评估嵌入质量。我们可以借鉴这些工具来诊断和验证自己的分解策略是否有效。

5. **⚖️ 充分条件≠必要条件**：CI原则是一个保守的充分条件。在实际应用中，即使分解组件不能完全独立，只要它们之间的相关性足够低，仍然可以获得性能提升。这给了我们更大的灵活性——不必追求完美的独立性，而是追求"足够好"的分解。

- **关键词**: 持续时空预测 (Continual Spatio-Temporal Forecasting)、上下文模式库 (Contextual Pattern Bank)、频域网络 (FreNet)、双流线性图注意力 (DLGA)、灾难性遗忘 (Catastrophic Forgetting)、分布漂移 (Distribution Shift)
- **代码**: https://github.com/Aoyu-Liu/STBP

## 研究问题与动机

### 核心问题
现有时空图神经网络（STGNNs）大多基于"固定拓扑 + 离线训练"范式，无法适应真实世界中图结构持续扩展、数据分布不断漂移的流式场景。虽然已有持续时空预测（CSTF）方法被提出，但存在两个关键不足：

1. **通用骨干网络建模能力有限**：多数CSTF方法采用简单的CNN+GCN堆叠作为骨干，难以有效处理动态变化的时空相关性和长期分布漂移；强行将现有STGNN适配为持续学习往往导致性能退化。
2. **持续优化策略与骨干耦合薄弱**：基于动态结构扩展的策略（如直接参数扩展、提示拼接）与骨干网络的协作不够紧密，难以在模型稳定性、适应性和可解释性之间取得良好平衡。

### 四大关键挑战
论文认为理想的CSTF框架应同时解决：
- ❶ 处理分布漂移（Distribution Drift）
- ❷ 建模动态时空相关性（Dynamic Spatio-Temporal Correlations）
- ❸ 缓解灾难性遗忘（Catastrophic Forgetting）
- ❹ 设计与骨干高效协同的增量策略

### 与本项目的关联动机
在异常客流预测场景中，节假日/极端天气等事件会导致数据分布剧烈变化（类似分布漂移），且监测站点可能动态增减（类似图结构扩展）。传统离线模型难以应对这些持续演变的场景，STBP的持续学习框架为解决此类问题提供了新思路。

## 核心贡献

1. **高效通用的时空骨干网络**：专为持续预测任务设计，通过频域模块提取稳定时序分量以缓解分布漂移，通过轻量级线性图注意力建模动态空间相关性，且不依赖预定义邻接矩阵、与节点数量无关。
2. **基于Prompt引导的可扩展上下文模式库**：由可训练参数组成，通过参数扩展实现增量更新，利用门控和注意力机制与骨干交互，捕获节点级别的相关性（Relevance）与异质性（Heterogeneity），有效缓解灾难性遗忘。
3. **全面的实验验证**：在三个真实数据集上显著优于SOTA基线，在预测精度、适应性和可扩展性方面均表现出色。

## 方法概述

STBP框架由两大核心组件构成：

### 整体工作流
- **初始训练阶段**（$\tau=1$）：骨干网络与上下文模式库联合训练，捕获当前数据的时空相关性。
- **后续增量阶段**（$\tau>1$）：**骨干网络冻结**（❄️）以保留历史知识，**仅更新上下文模式库**（🔥）——通过参数扩展和微调来适应新场景。模式库作为Prompt引导冻结的骨干适应新数据分布。

### 形式化定义
- **流式时空图**：$\mathcal{G} = \{G_\tau\}_{\tau=1}^{T}$，其中 $G_\tau = (V_\tau, E_\tau, A_\tau)$，节点数 $N_\tau = |V_\tau|$ 随时间递增。
- **持续时空预测目标**：在每个增量期 $\tau$，给定当前图 $G_\tau$ 和历史观测 $X_\tau \in \mathbb{R}^{N_\tau \times T_h}$，预测未来信号 $\hat{Y}_\tau = f_\theta(G_\tau, X_\tau)$，其中 $T_h$ 为历史窗口长度，$T_f$ 为预测步长。

## 关键技术细节

### 1. 上下文模式库（Contextual Pattern Bank）

#### 基本结构
- 可扩展的参数矩阵 $P_\tau \in \mathbb{R}^{N_\tau \times d}$，由可训练参数组成。
- 包含三组参数：$P_\tau^{(0)}, P_\tau^{(1)}, P_\tau^{(2)} \in \mathbb{R}^{N_\tau \times d}$，分别承担不同功能。

#### 增量扩展机制
$$P'_\tau = P_{\tau-1} \| \Delta P_\tau$$
其中 $\Delta P_\tau \in \mathbb{R}^{(N_\tau - N_{\tau-1}) \times d}$ 为新增节点的参数。仅对扩展后的模式库 $P'_\tau$ 进行微调，骨干保持冻结。

#### Prompt引导机制
- **门控函数**（建模节点异质性）：
  $$H'_\tau = P_\tau^{(1)} \cdot h_\theta(H_\tau \cdot (1 + P_\tau^{(0)}))$$
  其中 $h_\theta$ 为骨干中的任意子模块。
- **注意力引导**（建模节点相关性）：$P_\tau^{(2)}$ 作为Key嵌入注入注意力模块，引导骨干泛化相关性感知信息。

#### 核心洞察
- t-SNE可视化表明，即使没有显式聚类约束，模式库通过数据驱动的参数学习自主区分了异质和相关节点。
- 编码的是高层抽象而非原始历史数据，因此在**隐私保护**和**存储效率**方面具有优势。

### 2. 通用时空骨干网络

#### 频域网络（FreNet）
用于提取稳定的时序分量（周期性、趋势），抑制高频噪声，增强对分布漂移的鲁棒性。

$$H^f_\tau = \text{IFFT}(\text{FFT}(H_\tau) \odot F_\tau)$$

- 输入 $X_\tau \in \mathbb{R}^{N_\tau \times T_h}$ 经线性层映射到高维表示 $H_\tau \in \mathbb{R}^{N_\tau \times d}$。
- 通过FFT变换到频域，与可学习的频域嵌入 $F_\tau \in \mathbb{C}^{(d/2+1)}$ 逐元素相乘，自适应突出稳定特征。
- IFFT返回时域后经线性层处理，再与模式库 $P_\tau^{(0)}$ 通过门控交互。
- 骨干首尾各一个FreNet：第一个做升维+频域滤波，第二个做降维恢复原始形状。
- 相比RNN/TCN，FreNet计算效率更高，且更好地提取抗分布漂移的稳定低频分量。

#### 双流线性图注意力（DLGA）
解决传统图注意力 $O(N^2)$ 复杂度问题，同时融合模式库知识。

**标准注意力**：
$$Q = W_q H^s_\tau, \quad K = W_k H^s_\tau, \quad V = W_v H^s_\tau$$
$$H^{s'}_\tau = \text{Attention}(Q, K, V, P_\tau^{(2)}) = \text{Softmax}(QK^\top + Q(P_\tau^{(2)})^\top)V$$

**线性近似**（随机特征映射 $\phi(\cdot)$）：
$$\text{Attention}(Q, K, V, P_\tau^{(2)}) \approx \phi(Q)\left(\phi(K)^\top V + \phi(P_\tau^{(2)})^\top V\right)$$

- 将复杂度从 $O(N^2)$ 降至 $O(N)$。
- **双流设计**：$P_\tau^{(2)}$ 作为额外的Key，使模型能评估演化输入模式与已存储知识之间的关系。
- 不显式构建邻接矩阵，而是通过重排注意力运算隐式建模动态相关性。
- 无需预定义图结构，天然支持图的动态扩展。

### 3. 整体架构流程
```
输入 → FreNet(升维+频域滤波) → [与P^(0)门控交互] → DLGA(含P^(2)作为Key) → FeedForward → FreNet(降维恢复) → 预测层
                                    ↑                          ↑
                              P^(1)·hθ(H·(1+P^(0)))      P^(2) as Key
```

## 实验

### 数据集

| 数据集 | 领域 | 时间范围 | 节点扩展 | 相对增长 | 采样频率 | 特点 |
|--------|------|----------|----------|----------|----------|------|
| PEMS-Stream | 交通流量 | 2011.07-2017.09 | 655→871 | +33% | 5分钟 | 渐进式扩展，模拟长期基础设施增长 |
| CA-Stream | 交通流量 | 2019.01-2019.04 | 480→1698 | +254% | 5分钟 | 爆发式扩展，极端增量压力测试 |
| AIR-Stream | 空气质量 | 2016.01-2019.12 | 1087→1202 | +10% | 1小时 | 跨域验证，稳定扩展 |

- 所有数据集按 6:2:2 划分训练/验证/测试集。
- 预测任务：基于前12个时间步观测预测后12个时间步。
- MMD检验证实了各数据集存在显著的分布漂移（尤其是新增节点）。

### 基线方法

**传统时空预测模型**（每个增量期从头训练或在线训练）：
- GWNet：自适应邻接矩阵 + 图卷积 + 时序卷积
- STID：基于可训练嵌入的轻量MLP
- iTransformer：不依赖静态图结构的时序模型，在线微调

**持续时空预测模型**：
- TrafficStream：历史数据回放 + 参数平滑
- STKEC：基于影响力的知识扩展 + 记忆增强知识巩固
- PECPM：模式匹配维护交通模式库，无需历史数据
- STRAP：检索增强的多维模式库 + 即插即用Prompt
- EAC：动态Prompt池的Prompt调优（扩展+压缩）

### 主要结果

#### 总体性能（所有增量期平均）
| 数据集 | 指标 | 最佳基线(EAC) | STBP | 提升幅度 |
|--------|------|---------------|------|----------|
| PEMS-Stream | MAE | 15.67 | **12.31** | ↓21.44% |
| CA-Stream | MAE | 20.20 | **15.77** | ↓21.93% |
| AIR-Stream | MAE | 24.21 | **23.64** | ↓2.35% |

- STBP在所有三个数据集、所有预测步长（3/6/12步）上均取得最优。
- 相比全参数微调策略（TrafficStream/STKEC/PECPM），基于冻结骨干+轻量Prompt适配的方法（EAC/STRAP/STBP）平均精度更高。
- STRAP在CA-Stream上表现较差，说明检索式模式匹配在快速大规模拓扑扩展场景中失效。

#### Few-Shot预测
当后续增量期训练数据缩减至10%时，STBP仍大幅领先：
- PEMS-Stream MAE: 13.58 vs EAC的16.13
- CA-Stream MAE: 17.11 vs EAC的20.94

这证明持续学习机制能有效利用历史阶段积累的通用特征，在数据极度稀缺时仍能快速适应。

#### 消融实验
- **Retrain**（无模式库，每期重训）：性能最差，证实灾难性遗忘的严重影响。
- **Online**（无模式库，在线微调）：在交通数据集上与EAC相当，说明骨干本身具有良好的动态建模能力。
- **w/o Backbone**（替换为CNN+GCN骨干）：性能显著下降，证实通用骨干的不可替代性。
- **w/o DLGA**：性能大幅下降，验证了动态空间相关性建模和Prompt知识整合的关键作用。

#### 效率分析
- STBP虽骨干更复杂，但得益于频域处理和线性注意力，开销仅略高于EAC。
- 线性注意力将计算量从 $O(N^2)$ 降至 $O(N)$，随节点增长模式库仅引入线性额外开销。
- 在CA-Stream的大规模图扩展下仍保持SOTA性能和良好可扩展性。

#### 案例研究
- t-SNE可视化显示模式库在训练后形成有意义的聚类，同一簇内节点具有相似的周期和趋势模式。
- 新增节点能被正确归入已有簇，验证了模式库的泛化和持续适应能力。
- 实际预测可视化中，STBP比EAC更准确地捕获动态趋势。

## 与本项目的关联

### 直接适用性
1. **节假日/极端天气场景的分布漂移处理**：FreNet通过频域分析提取稳定的周期性和趋势分量，天然适合处理节假日导致的客流分布突变。异常事件相当于"分布漂移"，FreNet能抑制高频噪声、保留稳健的低频模式。
2. **监测站点动态增减**：DLGA不依赖预定义邻接矩阵，且上下文模式库支持参数扩展，可直接应对客流监测设备的动态部署/撤除。
3. **持续学习能力**：在实际运营中，模型需要不断学习新的节假日模式、新线路的客流规律，STBP的"冻结骨干+扩展模式库"范式允许在不重训的情况下持续适应。

### 可借鉴的设计思想
1. **频域稳定性提取**：可将FreNet思想应用于客流时间序列的特征提取，特别是在多尺度（日/周/月/年周期）分析中。
2. **节点级异质性建模**：不同类型的车站（枢纽站、景区站、通勤站）具有不同的异常响应模式，上下文模式库的"相关性+异质性"双重建模思路可用于区分各类站点的异常行为。
3. **Prompt引导的轻量适配**：在面对新的异常类型时，无需重训整个模型，仅需扩展少量参数即可适配，这对实时性要求高的异常预警系统尤为重要。
4. **线性注意力的效率优化**：对于大规模城市轨道网络（数百至上千站点），$O(N)$ 的注意力复杂度使得实时推理成为可能。

### 局限性考量
- STBP目前仅支持单任务持续学习，尚未扩展到跨域场景。若需同时处理多种异常类型（如节假日+天气+突发事件），可能需要进一步扩展。
- 论文的评估主要针对交通流量和空气质量，客流数据的特殊性（如更强的周期性、事件驱动的突发尖峰）需要额外验证。
- 上下文模式库的纯增量扩展可能导致参数量持续增长，长期运行需要考虑压缩或合并策略。

## 关键启发

1. **"稳定骨干 + 灵活适配"的分离设计是持续学习的理想范式**：骨干负责捕获通用、稳定的时空模式，轻量级可擴展组件负责适应新场景。这种设计避免了全参数微调导致的灾难性遗忘，也避免了固定模型的适应性不足。对于异常客流预测系统，可以设计类似的架构：通用时空编码器 + 场景特定的适配模块。

2. **频域方法是处理分布漂移的有效工具**：相比时域方法容易受到突变干扰，频域分析能自然地将信号分解为稳定的低频分量（周期、趋势）和不稳定的高频分量（噪声、突变）。这对异常检测有双重意义：既可以用稳定分量做基线预测，又可以用高频残差作为异常信号。

3. **参数化的上下文模式库比数据回放更适合生产环境**：模式库编码的是高层抽象而非原始数据，兼具隐私保护和存储效率优势。在客流预测的实际部署中，这意味着不需要保存大量历史敏感出行数据，仅需维护紧凑的参数矩阵。

4. **线性注意力是大规模图上的必备优化**：当站点数量达到数百甚至上千时，$O(N^2)$ 的注意力计算成为瓶颈。DLGA通过随机特征映射实现 $O(N)$ 复杂度，同时保持了动态相关性建模能力和Prompt知识的无缝集成，这一技巧可直接迁移到我们的系统中。

5. **Few-Shot能力验证了持续学习的实用价值**：在新站点刚部署、历史数据极少时，STBP仍能通过模式库中积累的通用知识做出合理预测。这对我们系统中新增监测点或新型异常事件的冷启动问题具有直接参考价值。

6. **节点异质性与相关性的显式区分有助于精细化预测**：不同类型站点对同一事件（如台风）的响应模式截然不同。模式库通过自主学习实现了这种区分，启示我们在异常客流预测中也应显式建模站点类型的差异化响应。

# ST03: DoFlow: Flow-Based Generative Models for Interventional and Counterfactual Forecasting on Time Series

## 基本信息
- **会议/期刊**: ICLR 2026 (International Conference on Learning Representations)
- **年份**: 2026
- **作者**: Dongze Wu, Yao Xie (Georgia Institute of Technology); Feng Qiu (Argonne National Laboratory)
- **关键词**: 因果时间序列预测、连续归一化流 (CNF)、干预预测、反事实预测、异常检测、有向无环图 (DAG)、结构因果模型 (SCM)、Conditional Flow Matching

## 研究问题与动机

传统时间序列预测模型（如 ARIMA、Transformer、RNN 等）本质上是**观测性 (observational)** 的：它们仅从历史数据中学习相关性并外推到未来，无法回答"如果……会怎样"的因果问题。然而在实际应用中，决策者常常需要回答两类因果查询：

1. **干预查询 (Interventional Query)**：如果我们对某些变量施加特定干预（例如改变水电涡轮控制信号），系统未来轨迹将如何变化？形式化为 $p(X_{\tau+1:T} | x_{1:\tau}, do(X_I := \gamma_I))$。
2. **反事实查询 (Counterfactual Query)**：给定已经观测到的事实轨迹，如果我们当时采取了不同的干预，该轨迹会变成什么样？形式化为 $p(X^{CF}_{\tau+1:T} | x_{1:\tau}, x^F_{\tau+1:T}, do(X_I := \gamma_I))$。

现有方法的不足：
- 大多数现代预测器仅支持观测预测，无法模拟干预和反事实轨迹。
- 现有时序因果效应方法主要关注离散、固定时间的处理效应估计，不支持对任意时刻连续变量的干预。
- **目前尚无通用框架支持基于因果 DAG 的反事实时间序列预测**。

## 核心贡献

1. **提出 DoFlow 框架**：首个在因果 DAG 上定义的基于连续归一化流 (CNF) 的生成模型，统一支持观测预测、干预预测和反事实预测三种模式。
2. **反事实恢复理论保证**：在单调 SCM 及标准因果假设下（Assumption 4.1），证明了 DoFlow 的编码-解码机制可以几乎必然地恢复真实反事实值（Corollary 4.5）。
3. **基于似然的异常检测**：DoFlow 为未来轨迹提供显式对数密度 $\log p_\theta(\hat{x}_{\tau+1:T} | \hat{H}_\tau)$，可用于原则性的异常检测——当上下文异常时，模型对其生成的预测轨迹赋予较低密度。
4. **广泛的实验验证**：在多种合成因果 DAG 结构（Tree、Diamond、FC-Layer、Chain）及两个真实数据集（水力发电系统、癌症治疗）上进行了全面评估。

## 方法概述

### 整体架构

DoFlow 在一个已知的因果 DAG 上运行，包含 $K$ 个节点 $\{1, \dots, K\}$，按拓扑排序排列。每个节点 $i$ 在时间步 $t$ 的值 $X_{i,t}$ 依赖于自身历史和父节点历史：

$$X_{i,t} := f_i(X_{i,t_-}, X_{pa(i),t_-}, U_{i,t})$$

其中 $U_{i,t}$ 是跨节点和时间独立的外生噪声。假设**同一时间步内无因果关系**（所有因果影响至少滞后一个时间步）。

### 核心组件

每个节点 $i$ 拥有独立的：
- **RNN 编码器**：LSTM/GRU，将节点及其父节点的历史压缩为隐状态 $H_{i,t-1} = \text{concat}(h_{i,t-1}, h_{pa(i),t-1})$
- **条件 CNF**：以 $H_{i,t-1}$ 为条件的连续归一化流，建模 $X_{i,t}$ 的条件分布

### 三种预测模式

| 模式 | 隐变量来源 | 条件状态 | 说明 |
|------|-----------|---------|------|
| 观测预测 | $z_{i,t} \sim \mathcal{N}(0,1)$ | $\hat{H}_{i,t-1}$（从预测值更新） | 标准自回归预测 |
| 干预预测 | $z_{i,t} \sim \mathcal{N}(0,1)$；被干预节点直接赋值 $\gamma_{i,t}$ | $\hat{H}_{i,t-1}$ | 干预通过 RNN 状态传播到下游 |
| 反事实预测 | $z^F_{i,t} = \Phi_\theta(x^F_{i,t}; H^F_{i,t-1})$（从事实轨迹编码） | $\hat{H}^{CF}_{i,t-1}$ | Abduction → Action → Prediction 三步流程 |

## 关键技术细节

### 1. 连续归一化流 (CNF) 基础

CNF 通过 Neural ODE 定义从目标分布 ($s=0$) 到基分布 $\mathcal{N}(0,1)$ ($s=1$) 的连续变换：

$$\frac{dx_{i,t}(s)}{ds} = v_i(x_{i,t}(s), s; H_{i,t-1}), \quad s \in [0,1]$$

- **前向过程（编码）**：$\Phi_\theta(x_{i,t}; H_{i,t-1}) = x_{i,t} + \int_0^1 v_i(x_{i,t}(s), s; H_{i,t-1}) ds$，将观测值推送到潜空间
- **反向过程（解码）**：$\Phi_\theta^{-1}(z_{i,t}; \hat{H}_{i,t-1}) = z_{i,t} - \int_0^1 v_i(x_{i,t}(s), s; \hat{H}_{i,t-1}) ds$，从潜空间生成预测

### 2. Conditional Flow Matching (CFM) 训练

使用线性插值参考路径 $\phi(x_{i,t}, z; s) = (1-s)x_{i,t} + sz$，其导数 $\partial_s \phi = z - x_{i,t}$ 作为参考速度场。训练损失为：

$$\mathcal{L}_{CFM}(\theta) = \mathbb{E}\left[\frac{1}{K(T-\tau)} \sum_{i=1}^K \sum_{t=\tau+1}^T \mathbb{E}_{s \sim \mathcal{U}[0,1], z \sim \mathcal{N}(0,I)} \|v_i(\phi(x_{i,t}, z; s), s; H_{i,t-1}) - \partial_s \phi\|_2^2\right]$$

### 3. 干预传播机制

推理时按拓扑排序逐节点预测：
- 被干预节点 $(i,t) \in I$：直接设置 $\hat{x}_{i,t} = \gamma_{i,t}$
- 非干预节点：从 CNF 采样生成
- 所有节点的 RNN 状态均从预测/干预值自回归更新，确保干预信息通过 DAG 边和 RNN 状态向下游传播

### 4. 反事实预测的 Abduction-Action-Prediction

遵循 Pearl 的标准三步流程：
1. **Abduction**：用事实隐状态 $H^F_{i,t-1}$ 将事实观测 $x^F_{i,t}$ 编码为 $z^F_{i,t} = \Phi_\theta(x^F_{i,t}; H^F_{i,t-1})$
2. **Action**：应用干预计划 $I$
3. **Prediction**：用反事实隐状态 $\hat{H}^{CF}_{i,t-1}$ 解码 $\hat{x}^{CF}_{i,t} = \Phi_\theta^{-1}(z^F_{i,t}; \hat{H}^{CF}_{i,t-1})$

关键洞察：由于 CNF 的可逆性，编码后的 $z^F_{i,t}$ 捕获了外生噪声 $U_t$ 的信息（Proposition 4.3），使得在不同条件下解码能产生正确的反事实。

### 5. 反事实恢复理论

**Assumption 4.1**:
- (A1) $U_t \perp\!\!\!\perp (X_{t_-}, X_{pa,t_-})$
- (A2) 结构方程 $f(\cdot, U_t)$ 对 $U_t$ 严格单调连续
- (A3) 编码后 $Z_t$ 满足 $p_\theta(Z_t | H_{t-1}) = q(Z_t)$（即完美训练下 CNF 将所有条件映射到同一基分布）

**Proposition 4.3**：在上述假设下，存在双射 $g: \mathcal{U} \to \mathcal{Z}$ 使得 $Z_t = g(U_t)$ a.s.，且该映射与历史状态无关。

**Corollary 4.5（反事实恢复）**：$\hat{X}^{CF}_t := \Phi_\theta^{-1}(Z^F_t; \hat{H}^{CF}_{t-1}) = X^{CF}_t$ a.s.，即 DoFlow 精确恢复真实反事实值。证明通过对时间步归纳完成。

### 6. 异常检测

利用 CNF 的显式密度计算（Liouville 连续性方程）：

$$\log p_\theta(\hat{x}_{\tau+1:T} | \hat{H}_\tau) = \sum_{t=\tau+1}^T \left[\log q(z_t) + \int_0^1 \nabla \cdot v_\theta(x_t(s), s; \hat{H}_{t-1}) ds\right]$$

当上下文包含异常模式时，模型对其生成的预测轨迹赋予较低的对数密度，从而触发异常警报。

### 7. 局限性

- **需要已知 DAG**：当前假设因果 DAG 已知且正确指定，以及因果充分性（无未观测混杂因子）
- **可扩展性**：每个节点训练独立的 flow 网络，但每个网络比 Transformer 浅得多，总体参数量适中
- 未来方向：与时序因果发现或去混杂因果生成模型结合

## 与本项目的关联

本项目目标是构建**节假日/极端天气场景下的异常客流预测系统**。DoFlow 提供了以下直接相关的技术启示：

1. **异常检测机制的直接借鉴**：DoFlow 基于生成模型对数密度的异常检测方法非常适合本项目的异常客流识别场景。正常客流模式下模型赋予高密度，而节假日/极端天气导致的异常客流会使对数密度显著下降。这种方法比传统的阈值法更具理论基础，且能提供预测性的异常预警（如水电站案例中提前 10-20 分钟检测）。

2. **干预预测用于情景分析**：本项目可以借鉴 DoFlow 的干预预测能力，回答诸如"如果某条地铁线路因极端天气停运，其他线路客流将如何变化"的问题。这需要将交通网络建模为因果 DAG，然后在特定节点上施加干预。

3. **因果 DAG 结构的重要性**：DoFlow 强调显式嵌入因果结构而非仅学习相关性。对于客流系统，站点之间的客流传播具有天然的因果结构（枢纽站→周边站、上游景点→下游商圈等），显式建模这种结构有助于提升异常场景下的预测鲁棒性。

4. **Flow-based 生成模型的概率优势**：相比 diffusion 模型，CNF 提供精确似然，这对异常评分至关重要。同时 CFM 训练方式避免了 ODE 仿真的高成本。

5. **局限性提醒**：DoFlow 要求已知因果 DAG，在实际客流系统中 DAG 可能需要通过领域知识或因果发现算法获取。此外，当前假设因果充分性（无未观测混杂），但在客流场景中天气、大型活动等混杂因素可能未被完全观测，需要考虑去混杂扩展。

## 关键启发

1. **CNF 的可逆性是统一三种预测模式的基石**：编码（前向）将观测映射到潜空间，解码（反向）从潜空间生成预测。反事实预测的关键在于：编码后的潜变量捕获了外生噪声信息，使其可以在不同条件下重新解码。这一 "encode-under-factual-condition → decode-under-counterfactual-condition" 范式值得在其他生成模型中推广。

2. **RNN + CNF 的分工设计精巧**：RNN 负责压缩历史信息为条件向量，CNF 负责在每个时间步建模条件分布。两者解耦使得每个模块可以更简单（3 层 MLP + LSTM hidden=15），总参数量反而比大型 Transformer 更少。

3. **Conditional Flow Matching 的训练效率**：CFM 通过直接回归参考速度场避免了 ODE 仿真的训练开销，使 CNF 的训练成本接近普通回归任务。这对于需要在大量节点上分别训练模型的 DAG 场景尤为重要。

4. **拓扑排序推理保证因果一致性**：按 DAG 拓扑序逐节点生成确保了父节点的预测先于子节点完成，使干预能正确地沿因果边传播。这是将静态因果生成模型扩展到时序的关键设计。

5. **理论保证的实践意义**：Corollary 4.5 的反事实恢复结果虽然在理想假设下成立，但它指导了模型设计方向——确保 CNF 训练充分以满足 (A3)，选择满足单调性的架构等。即使在实际中假设不完全满足，该理论也为模型行为提供了可解释的基准。

6. **异常检测的前瞻性价值**：DoFlow 的水电站案例展示了生成模型异常检测的核心优势——不仅能检测当前异常，还能**提前预警**。这是因为模型学习的是正常动力学，当系统开始偏离正常模式时（即使尚未达到故障阈值），对数密度已经开始下降。这对本项目的客流异常预警具有直接参考价值。

# ST04: UrbanGraph: Physics-Informed Spatiotemporal Dynamic Heterogeneous Graphs for Urban Microclimate Prediction

## 基本信息
- **会议/期刊**: ICLR 2026 (International Conference on Learning Representations)
- **年份**: 2026
- **作者**: Weilin Xin (NUS), Chenyu Huang (Tongji), Peilin Li (NUS), Jing Zhong (Tsinghua), Jiawei Yao (Tongji, 通讯作者)
- **关键词**: 物理信息图神经网络、动态异构图、城市微气候预测、时空建模、因果拓扑编码、RGCN、LSTM
- **代码与数据**: https://github.com/wlxin-nus/UrbanGraph.git

## 研究问题与动机

### 核心问题
城市微气候预测（如UTCI、PET、气温、风速、辐射温度、湿度等）对城市可持续发展和公共健康至关重要。该任务代表了一大类**城市时空物理场预测问题**（还包括城市风场模拟、污染物扩散预测等）。

### 现有方法的不足
1. **物理模拟方法**（CFD、ENVI-met）：物理保真度高，但计算开销巨大，无法用于大规模长时间序列预测。
2. **数据驱动方法**：
   - **CNN/网格模型**：受欧氏数据假设限制，难以捕获城市环境中非局部（如阴影跳跃中间空间）、各向异性（如定向风流）的长程不规则依赖。
   - **同质GNN**：采用统一的消息传递机制，无法区分不同物理过程（如植被蒸散 vs 建筑遮阳）；使用固定图结构，无法表征物理过程随环境条件的实时演变。
   - **生成式图模型**：隐式学习潜在图结构，缺乏物理一致性保证。
3. **Physics-Informed方法**：
   - **Learning bias**（软约束，如PDE残差损失）：训练开销大，效果有限（论文实验显示 $\Delta R^2 \approx +0.003$）。
   - **Inductive bias**（硬约束）：传统方式往往牺牲模型灵活性。

### 关键洞察
需要将物理第一性原理转化为**动态因果拓扑**，作为**结构化归纳偏置（structure-based inductive bias）**直接编码到图结构中，而非通过软约束或隐式学习。这种显式因果编码能有效缩减假设空间，防止模型从噪声中学习虚假相关。

## 核心贡献

1. **提出基于结构归纳偏置的动态拓扑重构方法**：将时变物理过程（遮阳、对流扩散、植被蒸散）显式编码为动态异构图的拓扑结构，作为硬约束注入图学习。这是一种新的将时变因果知识注入图学习的范式。

2. **设计动态异构图神经网络架构（UrbanGraph）**：
   - RGCN作为**物理算子近似器**：为不同关系类型（遮阳、对流等）分配专用可学习权重矩阵 $W_r$，实现物理过程解耦。
   - LSTM建模时间演化：与物理输运过程的马尔可夫性质对齐。
   - 相比最强基线LRGCN，FLOPs降低73.8%，训练速度提升21%，精度提升（$R^2$ 从0.8422提升至0.8542）。

3. **构建首个高分辨率时空微气候基准数据集 UMC4/12**：基于ENVI-met高保真模拟，包含新加坡396个城市街区、约1190万时空数据点、6个目标变量、12小时时间跨度。

4. **框架泛化性验证**：在UWF3D风场数据集（Navier-Stokes方程支配的矢量场）上同样取得优异表现（$R^2 > 0.88$），证明显式拓扑编码范式适用于由已知物理方程支配的各类城市时空动力学问题。

## 方法概述

UrbanGraph框架由两大核心组件构成：

### 1. 物理信息图表示（Physics-Informed Graph Representation）
在每个时间步 $t$，根据当前环境条件重建边集 $E_t$，包含5种边类型，分为动态和静态两类：

**动态边（Physics-Informed Dynamic Edges）**——每小时更新：

| 边类型 | 物理含义 | 构建规则 |
|--------|---------|---------|
| **Shading（遮阳）** | 方向性辐射遮挡 | 从遮挡物节点 $v_i$ 到地面节点 $v_j$ 建立有向边，条件：$d(v_i, v_j) \leq L_{shadow,t}$ 且角度偏差在 $\Delta\phi_{shadow}$ 内 |
| **Vegetation Evapotranspiration（植被蒸散）** | 太阳辐射依赖的生物物理交互 | 从树节点 $v_i$ 到距离 $\leq R_{activity,t}$ 的节点建立有向边 |
| **Convective Diffusion（对流扩散）** | 流体动力学各向异性 | 基于风调制的"有效距离" $d_{eff}(v_i, v_j) \leq R_{local}$ 建立边 |

**静态边（Static Semantic Topology）**——提供结构冗余：

| 边类型 | 物理含义 | 构建规则 |
|--------|---------|---------|
| **Semantic Similarity（语义相似）** | 非局部功能交互 | 归一化静态特征空间中的k近邻（$k=8$） |
| **Internal Contiguity（内部连续）** | 物体内部能量传递（热惯性） | Moore邻域（8邻居）连接 |

**关键公式**：
- 阴影长度：$L_{shadow,t} = h_{obj} / \tan(\theta_{elev,t})$
- 阴影方向：$\phi_{shadow,t} = (\phi_{azimuth,t} + 180°) \bmod 360°$
- 植被活动半径：$R_{activity,t} = R_{base} \cdot \text{clip}(I_t / 1000, 0.5, 1.2)$
- 风调制因子：$\alpha_{wind,t} = 1.0 + \lambda_{wind} \cdot \cos(\Delta\theta_{wind}) \cdot (v_{wind,t} / v_{max})$
- 有效距离：$d_{eff}(v_i, v_j) = d(v_i, v_j) / \alpha_{wind,t}$

### 2. UrbanGraph网络架构

```
输入 → Feature Encoders → Spatial Graph Encoder (3层RGCN) → Fusion MLP → LSTM → Prediction Head MLP → 输出
         ↑                        ↑                              ↑
    全局气象+时间编码          动态异构图序列                   空间特征⊕环境嵌入⊕时间嵌入
```

四个核心模块：

**(a) Feature Encoders**：MLP编码全局环境特征 $u^{env}_t$ 和时间特征 $u^{time}_t$。

**(b) Spatial Graph Encoder（RGCN）**：3层关系图卷积网络，核心更新公式：
$$h_i^{(l+1)} = \sigma\left(\sum_{r \in \mathcal{R}} \sum_{j \in \mathcal{N}_i^r} \frac{1}{c_{i,r}} W_r^{(l)} h_j^{(l)} + W_0^{(l)} h_i^{(l)}\right)$$
每种关系类型 $r$ 拥有独立的权重矩阵 $W_r$，实现**物理算子解耦**。

**(c) Spatio-Temporal Evolution Module（LSTM）**：
- 融合策略：$x^{LSTM}_{v,t} = \text{MLP}_{fusion}([h^{RGCN}_{v,t} \oplus e^{env}_t \oplus e^{time}_t])$
- 初始隐藏状态：$h_0 = \text{MLP}_{h0}(h^{RGCN}_{v,t_0})$（Warming-up机制，用初始图的空间特征初始化）
- 选择LSTM而非Attention的原因：与物理输运过程（如热扩散）的马尔可夫性质一致；解耦空间交互与时间演化，降低优化复杂度。

**(d) Prediction Head**：$\hat{y}_v = \text{MLP}_{head}(h^{LSTM}_{v,T_{pred}})$，单头架构一次性生成所有 $T_{pred}$ 步预测。

### 问题形式化
给定历史图观测序列 $\{G^t\}_{t=t_0-T_{hist}+1}^{t_0}$ 和对应上下文向量序列 $\{u^t\}$，学习目标变量 $k$ 的未来 $T_{pred}$ 步预测：
$$\{\hat{y}^{(k)}_{t_0+1}, \ldots, \hat{y}^{(k)}_{t_0+T_{pred}}\} = F^{(k)}\left(\{G^t\}, \{u^t\}, X\right)$$

## 关键技术细节

### 1. 显式因果剪枝 vs 隐式图学习
- **显式因果剪枝**（UrbanGraph）：利用物理第一性原理主动移除物理上不相关的连接（如移动的阴影），缩减搜索空间。
- **隐式循环学习**（如LRGCN）：通过数据驱动方式推断图结构演化，计算量大且可能学到虚假相关。
- 结果：FLOPs从 $3.49 \times 10^{10}$ 降至 $9.13 \times 10^9$（降低73.8%），训练时间从31.1s降至24.5s（提速21%）。

### 2. 硬约束 vs 软约束的物理注入
| 策略 | $R^2$ | RMSE | 训练速度(epoch/s) |
|------|-------|------|-------------------|
| Baseline (纯数据驱动) | 0.7846 | 1.2918 | 11.96 |
| Soft Constraint (PINN) | 0.7876 | 1.3028 | 12.10 |
| Hard Constraint (UrbanGraph) | **0.8542** | **1.0535** | 24.48 |

硬结构约束带来的精度增益是软损失约束的**23倍以上**。

### 3. 异构性的价值
- 异构图（RGCN）$R^2 = 0.8629$ vs 同质图（GCN）$R^2 = 0.8336$，提升约3.5%。
- 原因：同质图中单一参数集拟合不同物理定律导致**因果纠缠**；异构性通过物理算子解耦解决此问题。

### 4. 动态图的价值
- 动态图 $R^2 = 0.8629$ vs 静态图 $R^2 = 0.8057$，提升约7.1%。
- 原因：动态机制主动移除物理上不相关的连接（如随时间移动的阴影），降低优化难度。

### 5. 各边类型的贡献消融
移除Shadow和Local Wind边导致最显著的性能下降，证实显式建模时变物理过程的关键作用。Similarity边的移除也导致明显下降，说明非局部空间交互在城市微气候预测中不可或缺。

### 6. 其他重要发现
- **融合策略**：简单拼接（Concatenation）优于Attention和乘法融合。
- **预测头**：Single-Head优于Multi-Head（短预测窗口下更有效利用最终隐藏状态）。
- **Warming-up机制**：用初始图空间特征初始化LSTM隐藏状态，$R^2$ 从0.8510提升至0.8629。
- **边属性/边权重**：显式注入边属性和权重反而未带来提升，模型可从动态拓扑和节点特征中隐式学习交互强度。
- **单任务 vs 多任务**：STL一致优于MTL，因不同变量的物理机制差异导致负迁移。
- **数据效率**：40-60%训练数据即可获得大部分性能增益，90%后趋于饱和。

- **UMC4/12**（主数据集）：基于ENVI-met高保真模拟生成。新加坡11个1km²代表性站点（分层采样覆盖超高密度商业区到大型公园住宅区），水平分辨率4m，垂直分辨率3m。396个城市街区，每块2500节点，12小时（08:00-19:00），6个目标变量（UTCI/PET/AT/MRT/WS/RH），约1190万时空数据点。划分：训练70%/验证20%/测试10%（测试集为空间上未见过的街区）。

## 与本项目的关联

### 直接相关性
本项目目标是构建**异常客流预测系统**（节假日/极端天气场景），UrbanGraph虽面向城市微气候预测，但其方法论对本项目有高度参考价值：

1. **物理信息驱动的动态图构建思路可迁移**：UrbanGraph将物理第一性原理转化为动态因果拓扑的思想，可以类比到客流场景中——将**出行规律、交通网络拓扑、事件影响传播机制**等领域知识编码为动态异构图结构。例如：
   - 节假日场景 → 类似"遮阳边"的时变因果关系（景区→交通枢纽的客流传导随时间变化）
   - 极端天气 → 类似"对流扩散边"的各向异性影响传播（暴雨导致特定方向的客流骤降）
   - 不同交通方式/区域类型 → 异质边类型实现物理过程解耦

2. **显式因果剪枝的效率优势**：对于大规模城市级客流预测，显式基于领域知识剪枝比隐式图学习更高效（FLOPs降低73.8%），这对实时预警系统尤为重要。

3. **动态异构图处理时空演变的范式**：客流网络的拓扑在节假日/极端天气下会发生剧烈变化（如临时封站、限流措施），UrbanGraph的动态图重构机制提供了处理此类时变拓扑的参考方案。

4. **硬约束 vs 软约束的选择启示**：论文证实硬结构约束远优于软损失约束，提示我们在客流预测中也应优先将领域知识编码为模型结构而非仅作为正则化项。

### 需要注意的差异
- 微气候是连续物理场（可由PDE描述），客流是离散社会行为（受人为因素影响更大），物理规则的确定性程度不同。
- UrbanGraph的数据来自高保真物理模拟，而客流数据来自真实观测，噪声模式和分布特性不同。
- 论文提到的**Hybrid Topology**（物理图+可学习残差图）未来方向，对客流场景尤其重要——因为客流中存在大量未被建模的社会行为模式。

## 关键启发

1. **"结构即知识"的设计哲学**：与其让模型从数据中隐式学习复杂物理关系，不如将已知的因果关系直接编码为图拓扑的硬约束。这不仅提升精度，还大幅降低计算成本。对客流预测而言，应将交通网络结构、OD规律、事件传播路径等先验知识融入图结构设计。

2. **异构消息传递实现过程解耦**：不同类型的交互应由不同的可学习算子处理。在客流场景中，通勤客流、旅游客流、应急疏散客流等应使用不同的消息传递通道，避免因果纠缠。

3. **动态拓扑重构作为因果剪枝**：不是简单地添加/删除边，而是基于外部驱动因素（如天气、事件、时刻）按物理规则主动重构图结构。这比数据驱动的隐式图演化更高效、更可解释。

4. **时空解耦设计的合理性**：空间交互（RGCN）和时间演化（LSTM）的解耦设计，使每个模块专注于其擅长的维度。在客流预测中也可考虑类似解耦，而非使用时空耦合的复杂算子。

5. **单任务学习的优势**：当目标变量的物理机制差异较大时，共享表示可能导致负迁移。在多场景客流预测中，需审慎评估多任务学习是否真正有益。

6. **数据效率与泛化**：显式物理编码显著提升数据效率（40-60%数据即可获大部分性能），这对异常场景数据稀缺的客流预测尤为重要。

7. **边界参数的设定策略**：物理边界的阈值参数应参考文献中的经验值作为结构性约束的上界，在此范围内由网络自适应学习实际交互强度。这种"有界自由"的策略平衡了物理一致性与模型灵活性。

# ST05: Bridging Past and Future: Distribution-Aware Alignment for Time Series Forecasting

## 基本信息
- **会议/期刊**: ICLR 2026
- **年份**: 2026
- **作者**: Yifan Hu (清华大学), Jie Yang (UIC), Tian Zhou (阿里达摩院, 项目负责人), Peiyuan Liu (清华大学), Yujin Tang (Dartmouth College), Rong Jin (阿里达摩院), Liang Sun (阿里达摩院, 通讯作者)
- **关键词**: 时间序列预测、分布对齐、表示学习、重建辅助训练、互信息最大化、即插即用框架
- **代码**: https://github.com/TROUBADOUR000/TimeAlign

## 研究问题与动机

本文指出现有时间序列预测（TSF）模型在表示学习方面存在三个根本性缺陷：

1. **低频周期性捷径（Shortcut through Low-Frequency Periodicity）**：模型在纯误差驱动目标（MSE/MAE）下优化时，倾向于过度依赖低频周期分量。预测结果往往只是历史低频周期信号的重复，patch间的余弦相似度极高。而真实值中的高频分量（反映突变和非周期性波动）被严重低估，但这些高频信号对鲁棒预测不可或缺。

2. **过去与未来的分布失配（Distributional Mismatch between Past and Future）**：从历史序列提取的高维表示的分布与未来目标的分布存在显著差异。嵌入倾向于保留过去的统计特征而非未来的特征，导致将历史嵌入直接映射到目标分布变得困难。

3. **单向范式的结构性缺陷（Structural Flaw of Unidirectional Paradigm）**：主流预测范式是单向的（历史→预测），这种结构限制了模型保留目标关键信息的能力。随着表示逐层编码，过程类似于频率平滑器，丢弃了精细的频率结构（这些细节通常编码了由时变外部事件触发的突变信息）。

**核心问题**：能否设计一个预测框架，弥合过去与未来之间的鸿沟，在缓解分布偏移的同时忠实捕捉多频率动态？

## 核心贡献

1. **范式转变（Paradigm Shift）**：重新审视当前主流预测范式中的表示学习，揭示其过度强调低频周期性、分布失配和丢失精细分量的关键局限。提出融合"预测-重建-对齐"的新范式。

2. **技术贡献（TimeAlign框架）**：提出双分支框架，包含预测分支和重建分支，通过全局和局部对齐机制对两者的潜在表示进行分布感知对齐，有效弥合过去与未来。

3. **理论与实践统一**：提供两个理论保证：(i) 重建改善预测泛化能力；(ii) 对齐增强预测表示与未来目标之间的互信息。在8个基准数据集上验证了SOTA性能。

## 方法概述

TimeAlign 是一个轻量级、即插即用的框架，核心思想是通过辅助重建任务来对齐预测表示和未来目标分布。

### 整体架构（四个组件）

```
历史输入 X → [Predict Branch] → Ŷ_pred (训练+推理)
                                      ↕ Distribution-Aware Alignment
未来输入 Y → [Reconstruct Branch] → Ŷ_recon (仅训练)
```

总损失函数：
$$\mathcal{L} = \mathcal{L}_{pred} + \mathcal{L}_{recon} + \lambda \mathcal{L}_{align}$$

### Predict Branch（预测分支）
- 训练和推理阶段均激活
- 骨干网络可替换（plug-and-play），默认使用轻量级Linear编码器
- 输入 $X \in \mathbb{R}^{C \times L}$ 经Patching和线性投影得到 $X_p \in \mathbb{R}^{(C \cdot N) \times D}$
- 经过 $M$ 层编码器（Linear-Activation-Linear + 残差连接）：
  $$H_x^l = H_x^{l-1} + \text{Linear}(\sigma(\text{Linear}(H_x^{l-1}))), \quad l = 1, \ldots, M$$
- 预测头输出 $\hat{Y}_{pred} = \text{Linear}(H_x^M)$

### Reconstruct Branch（重建分支）
- **仅在训练阶段激活**，推理时丢弃
- 对未来序列 $Y \in \mathbb{R}^{C \times T}$ 进行自身重建，捕获与目标分布对齐的紧凑表示
- 结构与Predict Branch相同（共享patch数量 $N$ 和编码器层数 $M$）
- 重建表示 $H_y$ 作为对齐的参考分布

**关键洞察**：重建嵌入天然与目标分布对齐（因为是从自身恢复自身），且重建鼓励关注频谱细节，同时保留粗粒度周期结构和细粒度高频变化。

## 关键技术细节

### Distribution-Aware Alignment（分布感知对齐）

#### 额外映射层
对齐前对预测分支施加额外的线性映射：
$$\tilde{H}_x^i = \text{Linear}(H_x^i) \in \mathbb{R}^{(C \cdot N) \times D}$$
- 作用：时序重定位和归一化，使预测分支特征与重建分支更兼容
- **非对称梯度流**：对齐损失的梯度仅通过此Linear层传播到预测分支，重建分支stop-gradient，确保重建分支提供稳定的监督信号

#### Local Alignment（局部对齐）
保证patch级别的细粒度语义一致性，对捕捉突变和高频细节至关重要：
$$\mathcal{L}_{local}^i = \frac{1}{n^2} \sum_{j=1}^{n} \text{GELU}\left(1 - |\tilde{h}_{x,j}^i \cdot h_{y,j}^i| - \delta_{loc}\right)$$
其中 $n = C \cdot N$，$\delta_{loc}$ 为松弛margin。本质上度量频谱能量投影，利用多频率信息。

#### Global Alignment（全局对齐）
使特征内部的相对距离矩阵尽可能相似，确保大尺度时序依赖和低频动态也被对齐：
$$\mathcal{L}_{global}^i = \frac{1}{n^2} \sum_{j=1}^{n} \text{GELU}\left(\|\tilde{h}_{x,j}^i (\tilde{h}_{x,j}^i)^\top - h_{y,j}^i (h_{y,j}^i)^\top\|_1 - \delta_{glo}\right)$$

#### Weight-Based Dynamic Loss（自适应权重动态损失）
$$\mathcal{L}_{align} = \frac{1}{M} \sum_{i=1}^{M} (\alpha \mathcal{L}_{local}^i + \beta \mathcal{L}_{global}^i)$$
自适应权重防止任一目标主导：
$$\alpha = \frac{\mathcal{L}_{local} + \mathcal{L}_{global}}{\mathcal{L}_{local}}, \quad \beta = \frac{\mathcal{L}_{local} + \mathcal{L}_{global}}{\mathcal{L}_{global}}$$

### 理论分析

#### 定理1：重建改善泛化
设 $M^*$ 为最优预测解，$M_1$ 为直接从训练样本得到的经验估计器，$M_2$ 为通过重建误差最小化导出一维表示后再学习的估计器。在集中界条件下：
$$\frac{|M_2 - M^*|_F}{|M^*|_F} \ll \frac{|M_1 - M^*|_F}{|M^*|_F}$$
即重建引导的估计器比直接经验估计器有更紧的近似界。（证明基于矩阵集中不等式和Davis-Kahan $\sin\theta$ 定理）

#### 定理2：TimeAlign是隐式互信息增强器
- **预测损失**提供互信息 $I(Y; H_x)$ 的变分下界：$I(Y; H_x) \geq -\mathcal{L}_{pred}$
- **对齐损失**基于InfoNCE推导互补下界：$I(Y; H_x) \geq -\mathcal{L}_{align}$，其中密度比 $f(y, h_x) = \exp(\text{proj}(h_x)^\top \cdot G_\phi(y))$
- 联合优化 $\mathcal{L}_{pred}$ 和 $\mathcal{L}_{align}$ 等价于最大化预测表示与未来目标之间的互信息

## 实验

### 数据集
8个广泛使用的真实世界数据集：
- **ETT系列**：ETTh1, ETTh2, ETTm1, ETTm2（电力变压器温度，7通道）
- **Weather**：德国21个气象指标，10分钟采样
- **Electricity**：321个客户的小时用电量
- **Traffic**：旧金山湾区862个检测器的小时道路占用率
- **Solar-Energy**：阿拉巴马州137个光伏电站的10分钟太阳能产量
- 额外鲁棒性实验：NASDAQ和NYSE股票市场数据

### 基线方法
TimeMixer (2024), iTransformer (2024), PatchTST (2023), Crossformer (2023), TVNet (2025), ModernTCN (2024), TimesNet (2023), DLinear (2023), CMoS (2025), TimeBase (2025), Leddam (2024)

### 主要结果
- **长期预测**：在大多数数据集上取得最优性能。相比次优方法TVNet，MSE/MAE平均降低3.27%/5.20%，Wilcoxon检验p值为 $1.37 \times 10^{-8}$，在99%置信水平下显著
- **分布偏移严重的ETTm1/ETTm2数据集上优势尤为突出**
- **即插即用能力**：作为插件 augment iTransformer和DLinear，在大多数基准上一致提升1%-4%，同时提高预测与真值的余弦相似度
- **效率**：纯Linear架构，GPU显存和速度优于所有Transformer/CNN方法；在Traffic数据集上比vanilla iTransformer提前3000次迭代达到相同验证损失
- **消融实验**：Local+Global组合效果最佳；单独Global优于单独Local（粗粒度分布级拉伸更有效）；无对齐的基线本身已是SOTA级别，证明TimeAlign不是仅在弱基线上有效的trick
- **高频分析**：引入HF-MSE指标，验证TimeAlign在高频分量上的误差显著低于无对齐版本
- **股票市场鲁棒性**：在极端非平稳的NASDAQ/NYSE数据上一致优于所有基线

### 超参数
- 优化器：Adam，学习率从 $\{10^{-3}, 5 \times 10^{-4}, 10^{-4}\}$ 中选取
- Batch size：Electricity/Traffic为16，其余为32
- Look-back长度从 $\{96, 192, 336, 512, 720\}$ 中搜索
- 编码器层数：2层；所有实验在单张NVIDIA V100 32GB GPU上进行

## 与本项目的关联

本项目构建面向节假日/极端天气场景的异常客流预测系统，与本文有以下关键关联：

1. **分布偏移问题的直接对应**：节假日和极端天气场景下的客流模式与正常时段存在显著的分布偏移——这正是TimeAlign要解决的核心问题。历史正常客流的表示分布与异常场景下的未来目标分布差异巨大，TimeAlign的分布对齐机制可直接用于缓解这一挑战。

2. **高频突变信息的捕捉**：异常客流往往表现为突发的高频波动（如节假日前的客流骤增、极端天气导致的突然下降），而传统模型倾向于平滑掉这些高频信号。TimeAlign通过重建分支保留高频细节的能力，对本项目捕捉异常客流的突变特征具有重要参考价值。

3. **即插即用设计的工程价值**：TimeAlign可作为插件集成到任意预测骨干网络中，这意味着我们可以在现有的客流预测模型上直接叠加该模块，无需重构整个系统，降低了工程落地成本。

4. **重建分支作为"未来先验"**：在异常场景中，如果有部分异常时段的历史数据可用于重建分支的训练，则重建分支可以学习到异常场景的目标分布特征，为预测分支提供有效的分布引导。

5. **局限性注意**：论文指出在含有极端离群值和零填充值的数据集（如Weather、Solar）上，对齐可能失效甚至产生负面影响。客流数据中若存在类似的异常值或数据缺失问题，需要对齐模块做适配处理。

## 关键启发

1. **"预测-重建-对齐"三元范式**：不仅适用于通用TSF，对于任何存在训练/测试分布偏移的预测任务都有借鉴意义。在异常客流预测中，可以用异常时段数据构建重建分支，显式引导模型学习目标分布。

2. **重建不仅是预训练手段**：本文证明了重建损失最小化在理论上能获得比直接经验估计更优的泛化界，这为在异常客流系统中引入重建辅助训练提供了理论支撑。

3. **非对称梯度流设计**：重建分支stop-gradient是一个简洁而有效的设计，确保辅助分支提供稳定参考而不被主任务干扰。在多任务学习的异常预测系统中可采用类似策略。

4. **自适应权重避免手动调参**：Weight-Based Dynamic Loss根据当前loss值自动调整Local/Global对齐权重，减少了在不同场景（正常/节假日/极端天气）下手动调参的负担。

5. **高频保真度的重要性**：异常事件的本质就是高频信号。在设计异常客流预测系统时，应特别关注模型对高频分量的保留能力，可考虑引入类似HF-MSE的评估指标来监控模型对突变模式的捕捉效果。

6. **轻量化设计的启示**：TimeAlign仅用2层Linear编码器就达到SOTA，说明在分布对齐做得好的前提下，模型不一定需要很复杂。这对实时性要求高的客流预测系统有重要参考意义。

# ST06: ProtoTS: Learning Hierarchical Prototypes for Explainable Time Series Forecasting

## 基本信息
- **会议/期刊**: ICLR 2026 (International Conference on Learning Representations)
- **年份**: 2026
- **作者**: Ziheng Peng, Shijie Ren, Xinyue Gu, Linxiao Yang, Xiting Wang, Liang Sun（中国人民大学高瓴人工智能学院 + 阿里巴巴达摩院 + 湖畔实验室）
- **关键词**: 时间序列预测、可解释性、原型学习（Prototype Learning）、层次化原型、外生变量、专家引导（Expert Steering）
- **代码**: https://github.com/SKURA502/ProtoTS

## 研究问题与动机

深度学习在时间序列预测中取得了优异性能，但在高风险场景（电力负荷、能源管理、天气预测等）中，理解决策过程同样至关重要。现有可解释方法存在两大核心局限：

1. **输出侧（C1）**：现有方法（如TFT、DiPE-Linear）仅能解释单个时间步的预测，无法帮助用户理解**预测曲线整体趋势的成因**。例如，无法解释为什么电力负荷曲线在中午、下午和晚上分别出现三个峰值且逐渐递减。这种对整体时序模式的理解对于实际决策（如电力调度）至关重要。

2. **输入侧（C2）**：现有解释往往局限于某些类型的变量（如仅关注内生变量），无法揭示**异构输入变量之间的交互作用如何共同塑造时序模式**。例如，"极端夏季"的典型模式只有在同时考虑温度和季节变量时才能被观察到。

此外，现有基于原型的方法要么将原型作为中间表示（与输出脱节），要么仅将原型解码为单个输出变量（如分类标签），尚无工作将原型解码为**一段时序预测曲线**来实现整体时序动态的可解释性。

## 核心贡献

1. **首个将原型解码为时序预测曲线的框架**：每个原型对应一个完整的典型时序模式（如96步预测曲线），而非单个输出值，实现对整体时序模式的解释。

2. **层次化原型学习策略（Hierarchical Prototype Learning）**：通过树状结构组织原型——少量粗粒度根原型捕获全局模式保证可解释性，逐层细化的子原型捕获局部变化提升精度。支持专家选择性拆分特定原型，实现多粒度、用户友好的模型调整。

3. **多通道原型相似度计算（Multi-channel Prototype Similarity Computation）**：针对异构变量（离散/连续/内生/外生）设计分通道嵌入，结合瓶颈层融合机制建模变量间复杂交互并过滤噪声，提升预测精度与可解释性。

4. **新数据集LOF**：发布了包含22个协变量的合成电力负荷数据集，覆盖四个区域，为带外生变量的时间序列预测提供了新的基准。

5. **专家可引导性（Expert Steerability）**：案例研究表明，专家基于可解释的原型模式进行编辑后，春节期间MSE降低0.009，同时提升了可解释性。

## 方法概述

ProtoTS框架包含两个核心模块：

### 1. 多通道原型相似度计算模块
- **多通道嵌入**：内生变量通过非线性投影编码；外生变量按类型分为离散变量（嵌入表）和连续变量（变量特定的非线性投影），各自独立编码以保留异构信息。
- **瓶颈通道融合**：通过加法聚合所有变量嵌入，再经MLP-Mixer架构中的瓶颈层（$\mathbb{R}^d \to \mathbb{R}^{d_{bottle}} \to \mathbb{R}^d$，其中 $d_{bottle} \ll d$）过滤无关噪声，保留最具预测力的成分。先沿特征维度融合，再沿时间维度融合。
- **时序聚合**：将融合后的序列表示通过线性投影聚合为一维向量 $\hat{Z} \in \mathbb{R}^d$。
- **原型相似度计算**：计算 $\hat{Z}$ 与各原型嵌入 $\mu$ 的欧氏距离，经softmax得到相似度权重。

### 2. 层次化原型学习模块
- **根层学习**：使用少量根原型（如6个）捕获全局典型时序模式，预测为所有根原型时序模式的加权和：$\hat{Y}_{L+1:L+H} = \sum_{i=1}^{N} f(\hat{Z}|\mu_i) \cdot p_i$
- **分裂策略**：收敛后，根据归一化损失选择需要细化的叶原型，将其分裂为 $M$ 个子原型。子原型相似度在局部组内计算，最终预测为两层相似度的加权组合：$\hat{Y} = \sum_{i=1}^{N} f(\hat{Z}|\mu_i) \sum_{j=1}^{M} f(\hat{Z}|\mu_{i,j}) \cdot p_{i,j}$
- **分裂规则（Algorithm 1）**：基于训练实例的损失和原型激活频率，选择归一化损失最高的前 $\alpha\%$ 叶原型进行分裂，确保只对代表性不足的原型进行细化。
- **可扩展性**：支持多层级树状结构，任何叶原型均可继续分裂。

### 损失函数
$$\mathcal{L} = \|\hat{Y}_{L+1:L+H} - Y_{L+1:L+H}\|_1 - \lambda \sum_{i=1}^{N} f(\hat{Z}|\mu_i) \log(f(\hat{Z}|\mu_i))$$
第一项为L1预测损失，第二项为熵正则化，鼓励少数主原型覆盖大部分预测，增强可解释性。

## 关键技术细节

### 问题形式化
给定历史内生变量 $Y_{1:L} \in \mathbb{R}^{L \times 1}$、历史外生变量 $X_{1:L} \in \mathbb{R}^{L \times C}$ 以及未来外生变量 $X_{L+1:L+H} \in \mathbb{R}^{H \times C}$（如天气预报、日历变量等已知未来信息），预测未来 $H$ 步内生变量 $\hat{Y}_{L+1:L+H}$：
$$\hat{Y}_{L+1:L+H} = F(Y_{1:L}, X_{1:L}, X_{L+1:L+H})$$

### 多通道嵌入公式
$$Z_t = \begin{cases} \gamma(y_t) + \sum_{j=1}^{C_{dis}} E_j(x^{dis}_{t,j}) + \sum_{j=1}^{C_{con}} \psi_j(x^{con}_{t,j}), & t \in [1:L] \\ \sum_{j=1}^{C_{dis}} E_j(x^{dis}_{t,j}) + \sum_{j=1}^{C_{con}} \psi_j(x^{con}_{t,j}), & t \in [L+1:L+H] \end{cases}$$
预测窗口内无内生变量可用，仅依赖外生变量构建表示。

### 瓶颈融合机制
采用MLP-Mixer架构，交替进行特征维度和时间维度的瓶颈融合：
$$Z^{(l+1)}_{1:L+H} = \text{MLP}_{time}(\text{MLP}_{feature}(Z^{(l)T}_{1:L+H}))^T$$
瓶颈层可堆叠，$l$ 为层索引。融合后经线性聚合得到统一的一维表示用于原型匹配。

### 原型时间模式对齐
每个原型的时序模式 $p \in \mathbb{R}^T$ 定义在预定义周期 $T$ 上，预测时根据相位和长度与预测窗口 $H$ 对齐（类似CycleNet的做法）。

### 超参数设置
- 瓶颈融合块数：{1, 2, 3}
- 模型维度：{32, 64, 128, 256, 512}
- 初始原型数：{6, 8, 12}
- 最大层级深度：{1, 2, 3}
- 每个原型分裂数：{2, 3}
- 优化器：Adam，最大30个epoch，早停

## 实验

### 数据集
- **LOF（Load Forecasting）**：合成电力负荷数据集，覆盖4个区域（RE/YC/EA/PC），3年数据，15分钟采样间隔，22个外生变量（14个离散时间相关变量 + 8个连续天气变量）。Look-back=384, Forecast=96。
- **EPF（Electricity Price Forecasting）**：北欧5个电力市场的日前电价数据（NP/PJM/BE/FR/DE），6年数据，1小时采样间隔，6个协变量。Look-back=168, Forecast=24。
- **多变量预测基准**：ETTh1/h2, ETTm1/m2, Weather, Exchange（附录G）。

### 基线方法
- **深度学习方法**：TimeXer, iTransformer, TiDE, TFT, NBEATSx
- **机器学习方法**：XGBoost, LightGBM, pyGAM
- 所有深度学习模型均支持外生变量输入，TimeXer和iTransformer还扩展支持了未来协变量。

### 主要结果

**LOF数据集（MAE）**：
| 模型 | RE | YC | EA | PC | Avg | Δ |
|------|-----|-----|-----|-----|------|---|
| ProtoTS | **0.198** | **0.055** | **0.059** | **0.112** | **0.106** | - |
| TimeXer | 0.272 | 0.079 | 0.096 | 0.182 | 0.157 | 32% |
| TiDE | 0.253 | 0.057 | 0.061 | 0.164 | 0.134 | 21% |
| iTransformer | 0.279 | 0.080 | 0.097 | 0.139 | 0.149 | 29% |

ProtoTS相比最优基线，MSE降低48.3%，MAE降低20.9%。

**EPF数据集（MAE）**：ProtoTS在全部5个市场取得最优，平均MSE降低8%，MAE降低8%。

**消融实验**：移除瓶颈层、多通道嵌入或层次结构中任一组件均导致性能下降，完整模型效果最佳。

**数据效率**：当训练数据从100%减少到50%时，ProtoTS性能下降远小于TimeXer/iTransformer/TiDE等基线，展现出更高的数据效率。

**可解释性量化评估**：
- User Precision（UPrec）：ProtoTS 77±3.6% vs TFT 64±3.4% vs NBEATSx 62±2.8%
- SUS可用性评分：ProtoTS 73.36 vs NBEATSx 38.66 vs TFT 29.74

### 案例研究亮点
- 6个根原型自动学习到：工作日、非工作日、假日、冬季、温和温度、夏季等高层概念对应的典型负荷模式。
- 子原型进一步细分：如"假日"原型分裂出"春节"和"普通假日"两个子模式，春节模式呈现更显著的晚间峰值和平坦的午间峰值。
- 专家手动将春节原型进一步拆分为"基础模式"和"特殊模式"（农历正月初一起激活递增），MSE从0.099降至0.090。

### 局限性讨论
1. **非周期性模式适应性有限**：对高度不规则、非重复的时间序列效果下降，需要更多原型覆盖多样模式。
2. **依赖领域专家知识**：原型编辑需要足够的领域知识和人工投入。
3. **计算开销较大**：每迭代训练时间约40.8ms，高于iTransformer(12.5ms)和TiDE(11.1ms)。

## 与本项目的关联

本项目聚焦于**节假日/极端天气场景下的异常客流预测**，与ProtoTS的研究高度契合：

1. **外生变量处理**：ProtoTS的多通道嵌入机制直接适用于我们的场景——节假日标志、天气数据、日历信息等异构外生变量正是异常客流的关键驱动因素。其瓶颈融合机制能有效过滤无关变量噪声，这对客流场景中大量潜在干扰因素尤为重要。

2. **原型模式与异常场景识别**：ProtoTS的原型天然对应"典型场景模式"。在我们的项目中，可以学习到"春运高峰"、"国庆黄金周"、"台风天"、"暴雪天"等异常客流的典型时序原型，每个原型直接展示完整的客流变化曲线，便于运营人员快速理解和决策。

3. **层次化结构与多粒度分析**：层次原型允许从粗到细地理解异常客流。例如，根层区分"节假日vs工作日vs极端天气"，子层进一步区分"长假vs短假"、"高温vs暴雨"等细粒度模式，非常适合客运系统的多层级运营分析。

4. **专家可引导性**：这是对本项目最有价值的特性之一。运营专家可以基于对特定节假日/天气场景的先验知识，直接编辑或拆分原型模式，将领域知识注入模型，弥补纯数据驱动方法在罕见异常事件上的不足。

5. **数据效率优势**：异常客流事件样本稀少，ProtoTS在小数据量下性能衰减缓慢的特性使其特别适合此类低频异常场景的预测。

6. **需注意的局限**：ProtoTS对非周期性模式适应性有限，而极端天气引发的客流异常可能具有高度不规则性；计算开销也需在实际部署中权衡。

## 关键启发

1. **原型即"场景模板"**：将原型理解为可解释的"场景模板"而非抽象向量，每个原型对应一种业务可理解的典型模式，这对高风险场景的信任建立至关重要。在客流预测中，这意味着每个异常场景都有对应的可视化"故事"。

2. **层次化是平衡精度与可解释性的关键**：少量粗粒度原型保证全局可理解性，逐层细化提升精度。这种设计思路可推广到其他需要兼顾准确性和透明度的预测系统。

3. **异构变量的分通道处理优于统一编码**：不同类型变量（离散/连续/内生/外生）应采用最适合其特性的编码方式，再通过瓶颈机制融合去噪。这比Transformer的单通道注意力更能保留异构信息的语义。

4. **未来已知信息的显式利用**：ProtoTS明确将未来外生变量（天气预报、日历）纳入输入，这在客流预测中同样可行——节假日安排、天气预报等信息通常可提前获取，应充分利用。

5. **熵正则化促进稀疏激活**：通过熵正则化鼓励少数原型主导预测，使得每次预测的解释简洁明了（通常由2-3个主要原型构成），避免"什么都有一点"的模糊解释。

6. **专家编辑闭环验证了可解释性的实用价值**：可解释性不仅是"好看"，更能通过专家干预切实提升模型性能。这为本项目构建"人机协同"的异常客流预测系统提供了方法论支撑。

7. **原型分裂规则的设计思想**：基于归一化损失选择最需要细化的原型，而非盲目增加原型数量，这种"按需细化"的策略值得在客流异常模式学习中借鉴。

# ST07: HyperD: Hybrid Periodicity Decoupling Framework for Traffic Forecasting

## 基本信息
- **会议/期刊**: AAAI-26 (The Fortieth AAAI Conference on Artificial Intelligence)
- **年份**: 2026
- **作者**: Minlan Shao, Zijian Zhang*, Yili Wang, Yiwei Dai, Xu Shen, Xin Wang* (吉林大学人工智能学院 & 计算机科学与技术学院)
- **关键词**: 交通预测、周期性解耦、可学习周期嵌入、频域建模、时空注意力、异常波动
- **代码**: https://github.com/ll121202/HyperD

## 研究问题与动机

交通预测面临两大核心挑战：

1. **复杂的空间依赖性**：路网中不同路段和传感器之间存在动态交互，空间依赖关系随时间变化。
2. **多尺度周期性模式与不规则波动的共存**：受人类日常作息驱动，交通流呈现显著的日周期和周周期模式；但同时，事故、恶劣天气等不可预测事件会引发不规则的高频波动。

现有方法的局限性：
- **隐式周期建模**（如趋势-季节分解方法）：周期信息被分散到趋势分量和季节分量中，忽略了跨时间尺度和空间位置的统一周期结构，无法直接建模连贯的周期模式。
- **不精确的分解**：传统分解方法不可学习、效率低，导致趋势与季节分量对齐不佳，难以捕获复杂时序模式。
- **显式周期建模的不足**（如CycleNet）：仅考虑单一周期尺度，且未能建模空间位置与时序动态之间的交互，难以应用于交通预测场景。

**核心动机**：需要一个灵活的框架，能够同时捕获多尺度周期模式和细粒度的时空交互，并有效分离周期性成分与非周期性不规则波动。

## 核心贡献

1. **提出HyperD框架**：将交通数据解耦为**周期分量（Periodic）**和**残差分量（Residual）**，分别用定制化机制建模，解决多尺度周期模式与不规则波动并存的问题。
2. **混合周期表示模块（Hybrid Periodic Representation Module）**：利用可学习的日/周嵌入（Learnable Daily/Weekly Embeddings）和时空注意力编码器（STAE），显式捕获多尺度周期模式。
3. **频率感知残差表示模块（Frequency-Aware Residual Representation Module）**：通过复数域MLP在频域建模非周期高频波动，补充周期模式的不足。
4. **双视图对齐损失（Dual-View Alignment Loss, DVA）**：通过对齐低频信息与周期分支、高频信息与残差分支，确保两个分量的语义分离，防止信息冗余。
5. **全面的实验验证**：在4个真实数据集上达到SOTA，且在扰动下表现出优越的鲁棒性，计算效率显著优于已有解耦方法。

## 方法概述

### 问题定义

交通网络表示为有向图 $\mathcal{G} = \{\mathcal{V}, \mathcal{E}, \mathbf{A}\}$，其中 $\mathcal{V}$ 为 $N$ 个传感器节点，$\mathbf{A} \in \mathbb{R}^{N \times N}$ 为邻接矩阵。给定历史交通时序 $\mathbf{X} = \{\mathbf{x}_1, \ldots, \mathbf{x}_{T_1}\} \in \mathbb{R}^{T_1 \times N}$，预测未来 $T_2$ 步的交通状态 $\hat{\mathbf{Y}} \in \mathbb{R}^{T_2 \times N}$：

$$\mathbf{X}, \mathcal{G} \xrightarrow{f_\theta} \hat{\mathbf{Y}}$$

### 整体架构

HyperD包含三大组件：
1. **混合周期表示模块** → 生成周期预测 $\mathbf{S}^{out}$
2. **频率感知残差表示模块** → 生成残差预测 $\mathbf{R}^{out}$
3. **双视图对齐损失** → 训练时约束两分支的频率语义分离

最终预测：$\hat{\mathbf{Y}} = \mathbf{S}^{out} + \mathbf{R}^{out}$

## 关键技术细节

### 1. 混合周期表示模块（Hybrid Periodic Representation Module）

#### 1.1 可学习日/周嵌入（LDE / LWE）

- 引入两个可学习嵌入矩阵：$\mathbf{P}_D \in \mathbb{R}^{L_D \times N}$（日周期）和 $\mathbf{P}_W \in \mathbb{R}^{L_W \times N}$（周周期）
- 以5分钟采样率为例：$L_D = 288$（一天的时间步数），$L_W = 2016$（一周的时间步数）
- **统计先验初始化**：对训练数据归一化后，计算每个节点在每个时间步的均值作为嵌入初始值，加速收敛并融入时序先验知识
- 该设计可扩展至其他周期尺度（小时级、月级等）

#### 1.2 时空注意力编码器（STAE）

对周期嵌入 $\mathbf{P} \in \mathbb{R}^{L \times N}$ 进行精炼：

**Step 1 - GCN编码空间相关性**：
$$\mathbf{H} = \sigma(\hat{\mathbf{A}} \mathbf{P} \mathbf{W})$$
其中 $\hat{\mathbf{A}}$ 为归一化拉普拉斯矩阵。

**Step 2 - 时序自注意力**（每个时间步作为query）：
$$\mathbf{H}_t = \text{Attention}_t(\mathbf{H}) = \text{softmax}\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d}}\right)\mathbf{V}$$

**Step 3 - 空间自注意力**（每个节点作为query，对 $\mathbf{H}^\top$ 操作）：
$$\mathbf{H}_s = \text{Attention}_s(\mathbf{H}^\top)^\top$$

**Step 4 - 融合**：
$$\tilde{\mathbf{P}} = \mathbf{W}_o [\mathbf{H}_t ; \mathbf{H}_s]$$

分别对日和周嵌入独立执行上述操作，得到精炼后的 $\tilde{\mathbf{P}}_D$ 和 $\tilde{\mathbf{P}}_W$。

#### 1.3 混合周期模式构建

根据时间元数据（一天中的时刻 + 一周中的日期）从嵌入中检索对应片段：

- 历史时段：$\mathbf{S}^{in}_D(t) = \tilde{\mathbf{P}}_D[i^{in}_D(t), :]$，$\mathbf{S}^{in}_W(t) = \tilde{\mathbf{P}}_W[i^{in}_W(t), :]$
- 混合：$\mathbf{S}^{in} = \mathbf{S}^{in}_D + \mathbf{S}^{in}_W$
- 预测时段同理得到 $\mathbf{S}^{out}$

### 2. 频率感知残差表示模块（Frequency-Aware Residual Representation Module）

#### 2.1 残差计算

$$\mathbf{R}^{in} = \mathbf{X} - \mathbf{S}^{in}$$

#### 2.2 时空频率编码器（STFE）

将残差投影到高维空间 $\tilde{\mathbf{R}}^{in} \in \mathbb{R}^{T_1 \times N \times D}$ 后：

**空间维度频域处理**：
1. FFT：$\mathbf{R}^s_f = \text{FFT}_s(\tilde{\mathbf{R}}^{in})$
2. 复数域MLP（C-MLP）：在频域中用两组可学习权重 $(\mathbf{W}^r, \mathbf{W}^i)$ 分别处理实部和虚部
3. IFFT：$\mathbf{R}_s = \text{IFFT}_s(\mathbf{R}_2)$

**时间维度频域处理**：同样执行 FFT → C-MLP → IFFT 流程。

**输出**：$\mathbf{R}^{out} = \text{Proj}(\mathbf{R}_t + \tilde{\mathbf{R}}^{in})$（含残差连接）

> **关键洞察**：频域中的C-MLP等价于时域中的卷积操作，但能实现更高效的全局建模，且通过聚焦关键频率分量降低计算开销。

### 3. 双视图对齐损失（Dual-View Alignment Loss）

对预测 $\hat{\mathbf{Y}}$ 做FFT后，按阈值 $F_{low}$ 分割频谱：

$$\hat{\mathbf{Y}}^{low}_f = \hat{\mathbf{Y}}_f[0:F_{low}], \quad \hat{\mathbf{Y}}^{high}_f = \hat{\mathbf{Y}}_f[F_{low}:]$$

对齐损失：
$$\mathcal{L}_{dva} = \text{MSE}(\text{IFFT}(\hat{\mathbf{Y}}^{low}_f), \mathbf{S}^{out}) + \text{MSE}(\text{IFFT}(\hat{\mathbf{Y}}^{high}_f), \mathbf{R}^{out})$$

总损失：
$$\mathcal{L} = \mathcal{L}_{pred} + \alpha \cdot \mathcal{L}_{dva}$$

> **设计意图**：强制周期分支专注低频信息、残差分支专注高频信息，避免两分支语义重叠。

## 实验

- **数据集**: PEMS03, PEMS04, PEMS07, PEMS08（四个经典交通流数据集）
- **实验设置**: 训练/验证/测试 = 6:2:2；输入12步（1小时），预测12步（1小时）；所有结果取5次重复的平均值
- **基线方法**:
  - 时空预测方法：STGCN, DCRNN, GWNet, ASTGCN, MTGNN, STGODE, ST-WA, DGCRN, STPGNN
  - 时空解耦方法：D2STGNN, STWave, CycleNet-D, CycleNet-W, STDN
- **主要结果**:
  - HyperD在所有4个数据集上全面超越所有基线方法
  - 相比CycleNet-D/CycleNet-W，平均MAE分别降低22.63%和23.27%，验证了多尺度周期建模+时空交互的优势
  - 解耦方法整体优于非解耦方法，说明分量分离建模的有效性
- **消融实验**（PEMS04/PEMS08）:
  - 去除LWE比去除LDE性能下降更大 → 周周期包含工作日/周末动态，信息更丰富
  - 去除STFE比去除STAE性能下降更大 → 残差的时空建模比周期模式的时空建模更关键
  - C-MLP替换为普通MLP（Re-MLP）也有明显下降 → 频域建模不可替代
  - 去除DVA损失也有下降 → 频率对齐约束对解耦质量有实质贡献
- **初始化策略对比**: 统计先验初始化优于Zero/Uniform/Normal/Xavier/He等所有常规初始化
- **鲁棒性测试**（模拟三种扰动：突增×1.5、中断置零、片段打乱）:
  - HyperD在所有扰动类型下保持最低的性能降幅，鲁棒性显著优于D2STGNN、STWave、STDN
- **计算效率**（PEMS04, batch=64）:
  - 最大显存仅1.64GB（vs D2STGNN 17.90GB，降低6.27倍）
  - 每epoch训练时间7.31s（vs 57.29s，降低6.79倍）
  - CPU推理时间1.49s（vs 8.00s，降低4.77倍）
- **嵌入可视化**: HyperD学到的日/周嵌入比CycleNet更加展开和精细，捕获了更清晰的周期模式

## 与本项目的关联

本项目目标是构建**节假日/极端天气场景下的异常客流预测系统**。HyperD的核心思想与本需求高度相关：

1. **周期性解耦思路直接适用**：节假日和极端天气恰好属于论文所定义的"残差分量"——偏离常规日/周周期的不规则波动。HyperD将这类异常从周期模式中显式分离的思路，可为我们的异常检测提供结构化支撑。
2. **频率域分析视角**：DVA损失通过频域分割区分周期与异常，这一思路可用于识别"何时发生了异常"——当高频能量突增时即可能对应突发事件。
3. **鲁棒性验证方法值得借鉴**：论文中的三种扰动模拟（突增、中断、打乱）可作为我们评估模型在异常场景下鲁棒性的参考范式。
4. **局限性提醒**：论文的异常主要是短时、局部的扰动，而节假日/极端天气可能造成**持续性、全局性**的模式偏移，可能需要额外的机制（如外部特征注入、迁移学习）来增强。
5. **计算效率优势**：HyperD极低的资源消耗使其适合作为在线预测系统的基座模型，为异常检测模块留出充足的计算预算。

## 关键启发

1. **显式 > 隐式周期建模**：用可学习嵌入直接表示周期模式，比通过趋势-季节分解间接获取周期信息更有效。这启示我们在处理节假日周期时，也应考虑构建专门的"节假日嵌入"而非依赖通用分解。
2. **统计先验初始化的价值**：用历史均值初始化周期嵌入是一个简单但有效的技巧，在我们的系统中可以用历史同期（如去年同一节假日）的数据初始化异常模式嵌入。
3. **频域C-MLP的高效性**：在频域用复数MLP替代时域卷积，既降低了计算量又实现了全局感受野。对于大规模路网客流预测，这种效率优势尤为重要。
4. **解耦需要约束**：单纯的双分支结构不够，必须通过DVA等损失函数强制语义分离，否则两分支会趋于冗余。这对我们设计"正常客流+异常增量"的双分支预测架构有直接指导意义。
5. **残差分支更重要**：消融实验表明残差分支的时空建模对性能的贡献大于周期分支。这意味着在异常客流预测中，对异常/残差分量的精细建模可能是性能的关键瓶颈。
6. **多尺度周期叠加**：日周期+周周期的加法组合简洁有效，提示我们可以进一步加入"节假日周期"、"季节性周期"等更多尺度，以覆盖更丰富的模式。

# ST08: Generalising Traffic Forecasting to Regions Without Traffic Observations

## 基本信息
- **会议/期刊**: AAAI 2026 (The Fortieth AAAI Conference on Artificial Intelligence)
- **年份**: 2026
- **作者**: Xinyu Su, Majid Sarvi, Feng Liu, Egemen Tanin, Jianzhong Qi（墨尔本大学 & 香港科技大学广州）
- **关键词**: 交通预测、无观测区域泛化、物理信息神经网络(PINN)、外部信号融合、空间分组、LWR方程、对比学习
- **代码**: https://github.com/suzy0223/GenCast
- **扩展版**: https://arxiv.org/abs/2508.08947

## 研究问题与动机

### 核心问题
交通传感器部署成本高，导致空间覆盖稀疏且不均匀。现有模型在**有观测数据的区域**表现良好，但无法泛化到**完全没有交通观测数据的连续区域**（unobserved regions）。

### 现有方法的不足
1. **Kriging/外推方法**（如IGNNK、INCREASE、KITS）：主要针对零散的未观测点（scattered unobserved locations），在面对大面积连续无观测区域时泛化能力差。
2. **STSM**（当前SOTA）：通过遮蔽观测区域中与未观测区域"相似"的位置来训练，但相似度仅基于**静态辅助特征**（POI类别、地理坐标），无法捕获交通模式的**动态特性**。
3. **KITS**：在随机位置创建虚拟节点进行训练，隐式假设了已知密度的零散未观测点，引入了结构性先验，限制了向大连续未观测区域的泛化。

### 本文思路
利用两类更具通用性的引导信号来增强泛化能力：
1. **物理原理**（Physics Principles）：编码跨区域通用的内在交通动力学规律；
2. **动态外部信号**（Dynamic External Signals）：如天气数据，具有全域可用性且与交通模式强相关。

## 核心贡献

1. 提出 **GenCast** 模型，专门针对无观测区域的交通预测泛化问题。
2. 设计 **物理原理引导的损失函数** + **连续可微空间嵌入**，使PINN可在离散交通图上应用；以及 **跨域融合模块** 将动态天气信号与交通观测融合。
3. 提出 **空间分组模块（Spatial Grouping Module）**，过滤局部噪声信号，保留区域不变模式以增强泛化。
4. 在多个真实数据集上实验，GenCast一致优于SOTA基线，预测误差最高降低 **3.1%**，$R^2$ 最高提升 **125.6%**。

## 方法概述

### 整体架构
GenCast 基于对比学习骨架（backbone），包含四个核心模块：

```
观测图 Go → 随机遮蔽子图 → 掩码图 Gm_o
                                    ↓
            ┌──────────────────────────────────────┐
            │  1. 时空编码器 (Spatial-Temporal Encoder) │
            │     - 时间嵌入 TE_enc (正弦编码)          │
            │     - 空间嵌入 SE-L (LLM) / SE-H (GeoHash)│
            │     - STE层融合 → H0                      │
            ├──────────────────────────────────────┤
            │  2. 外部信号编码器 (External Signal Encoder)│
            │     - 天气数据按地理位置匹配               │
            │     - Cross-Attention + Gated Fusion → H0_fuse│
            ├──────────────────────────────────────┤
            │  3. ST Model + 空间分组模块               │
            │     - GCN + TCN 捕获时空依赖              │
            │     - 软分组 + 熵正则化                    │
            ├──────────────────────────────────────┤
            │  4. 物理信息模块 (Physics-informed Module) │
            │     - LWR残差 R = ∂X̂/∂t + (2X̂-X_fspd)·∂X̂/∂l│
            │     - Huber Loss 约束                     │
            └──────────────────────────────────────┘
```

### 训练目标
总损失函数由四项组成：

$$\mathcal{L} = \mathcal{L}_{pred} + \lambda \mathcal{L}_{cl} + \mu \mathcal{L}_{spg} + \theta \mathcal{L}_{phy}$$

- $\mathcal{L}_{pred}$：遮蔽位置的预测损失
- $\mathcal{L}_{cl}$：对比学习损失（原始视图 vs 掩码视图的一致性）
- $\mathcal{L}_{spg}$：空间分组熵正则化损失
- $\mathcal{L}_{phy}$：基于LWR方程的物理约束损失

除 $\mathcal{L}_{cl}$ 外，其余损失均在掩码图 $G^m_o$ 上计算，模拟未观测场景以增强泛化。

### 推理过程
1. 为未观测位置生成伪观测（pseudo-observations）；
2. 将 $G = G_o + G_u$（含伪观测）作为输入 $G^m$；
3. 前向传播生成预测，提取未观测位置的预测结果。

## 关键技术细节

### 1. 时空编码器（Spatial and Temporal Encoder）

**时间嵌入**：利用正弦函数编码每日周期位置：

$$TE_{enc} = \left[\sin\left(\frac{2\pi \cdot TE}{T_d}\right), \cos\left(\frac{2\pi \cdot TE}{T_d}\right)\right]$$

其中 $T_d$ 为每天的时间间隔数。

**空间嵌入（两种策略）**：

| 策略 | 名称 | 输入 | 处理方式 | 特点 |
|------|------|------|----------|------|
| SE-L | LLM-based | 地理坐标+POI+道路属性→文本描述 | 冻结LLaMA3-8B-Instruct取最后token嵌入 | 语义丰富但受时效性影响 |
| SE-H | GeoHash-based | 地理坐标→GeoHash字符串 | char-BERT + Transformer Encoder + Mean Pooling | 简单可训练，适应性强 |

> **关键设计意图**：这两种嵌入都是**连续可微的**，使得后续物理损失中的自动微分成为可能——这是将PINN应用于离散交通图的核心创新。

### 2. 外部信号编码器（External Signal Encoder）

- **数据源**：ECMWF ERA5-Land，9km×9km网格，每小时，4个变量（2m温度、地表净太阳辐射、地表径流、总降水量）。
- **匹配方式**：每个交通节点按最近邻匹配天气站点。
- **时间窗口**：$T_w = 12$小时历史天气上下文。
- **融合机制**：Cross-Attention + Gated Fusion：

$$H^0_{fuse} = \text{ReLU}\left(FC\left(z \odot H^0 + (1-z) \odot H_{wx}\right)\right)$$

$$z = \sigma\left(FC_s(H^0) + FC_t(H_{wx})\right)$$

### 3. 空间分组模块（Spatial Grouping Module）

**目的**：过滤个体位置的局部特异性信号（如交通事故引起的异常），保留组级别共享模式以增强泛化。

**机制**：
1. 对每层ST模型的输出 $H^l \in \mathbb{R}^{N_o \times T \times D}$ 做时间平均池化得 $H'^l \in \mathbb{R}^{N_o \times D}$；
2. 将 $D$ 通道分为 $c_g$ 组，reshape为 $(N_o \cdot c_g) \times d'$ 的样本；
3. 学习 $s_g$ 个空间组的中心表示 $C = \text{Softmax}(W_c) Z^l$；
4. 基于欧氏距离的softmax计算软分配权重：

$$W_s = \text{Softmax}(-\text{cdist}(Z^l, C)) \in \mathbb{R}^{(N_o \cdot c_g) \times (s_g \cdot c_g)}$$

5. **熵最小化损失**鼓励尖锐（接近one-hot）的分配：

$$\mathcal{L}_{spg} = \frac{1}{N \cdot c_g} \sum_{i=1}^{N \cdot c_g} \mathcal{H}(W_s[i,:])$$

### 4. 物理信息模块（Physics-informed Module）

**LWR方程**（交通流守恒定律）：

$$\frac{\partial \rho}{\partial t} + \frac{\partial (\rho x)}{\partial l} = 0$$

由于密度 $\rho$ 通常不可观测，利用Greenshields速度-密度关系 $x = x_{fspd}(1 - \rho/\rho_{max})$ 重写为纯速度形式：

$$R = \frac{\partial x}{\partial t} + (2x - x_{fspd})\frac{\partial x}{\partial l}$$

训练时使用模型预测值 $\hat{X}$ 和可微嵌入计算：

$$R = \frac{\partial \hat{X}}{\partial TE_{enc}} + (2\hat{X} - X_{fspd}) \cdot \frac{\partial \hat{X}}{\partial L_{enc}}$$

物理损失采用 **Huber Loss**：$\mathcal{L}_{phy} = \text{Huber}(R, \delta)$

> **自适应阈值策略**：先用RMSE warm-up一个epoch，计算残差的 $\tau$-分位数设定 $\delta$，然后重新初始化模型用Huber Loss训练。

### 数据集

## 与本项目的关联

### 直接相关性 ⭐⭐⭐⭐⭐
本文研究的**无观测区域泛化**问题与我们构建的**异常客流预测系统**高度相关：

1. **节假日/极端天气场景下的数据稀疏问题**：在极端天气或特殊节假日期间，部分区域的正常观测模式被打破，相当于这些区域暂时处于"类无观测"状态。GenCast利用外部天气信号补偿缺失信息的思路可直接借鉴。

2. **天气信号融合**：GenCast使用ERA5天气数据通过Cross-Attention+Gated Fusion与交通数据融合的方法，为我们处理极端天气场景下的客流预测提供了成熟的技术范式。我们的系统中天气是关键的异常触发因素，该融合机制值得直接采用。

3. **物理约束思想**：虽然LWR方程针对车辆交通，但其核心理念——**用领域知识约束模型以避免过拟合到观测数据的局部模式**——完全适用于客流预测。我们可以探索客流守恒、容量约束等类似的物理/领域先验。

4. **空间分组过滤局部噪声**：在异常场景中，个别站点的突发事件（如临时封站、活动散场）会产生不可泛化的局部信号。空间分组模块的思路可用于区分系统性异常与局部扰动。

5. **空间划分评估策略**：4:1:5的空间划分+多种切分方式取平均的评估方法，适合评估我们系统在未见区域的泛化能力。

### 可迁移技术
- 连续可微空间嵌入（使PINN适用于离散图）
- 门控融合机制（Gated Fusion）用于多模态信号整合
- 熵正则化的软分组策略
- Huber Loss自适应阈值策略

## 关键启发

1. **"外部知识补偿缺失观测"是泛化的核心思路**：当目标区域缺乏直接观测时，物理规律和外部动态信号（天气等）可作为桥梁连接已观测与未观测区域。这比单纯依赖静态特征（POI、坐标）更有效。

2. **让离散图结构支持自动微分是关键技术创新**：通过设计连续可微的空间/时间嵌入，使得原本只能在连续空间使用的PINN可以应用于离散交通图。这一思路在其他需要将物理约束引入图神经网络的场景中同样适用。

3. **过滤局部信号比捕获更多信号更重要**：空间分组模块的设计哲学是"少即是多"——通过熵正则化鼓励sharp assignment，主动抑制个体级别的特异性信号，保留组级别的可泛化模式。这对异常检测场景尤为重要，避免模型被偶发事件误导。

4. **动态外部信号 > 静态辅助特征**：论文的实验明确表明，天气等动态信号比POI等静态特征更能帮助泛化。对于我们的异常客流预测系统，应优先接入实时气象、大型活动日程等动态信号源。

5. **LLM生成的空间嵌入并非总是最优**：SE-L在老旧数据集和小范围同质区域表现不如简单的SE-H。提醒我们在实际应用中不要盲目追求复杂方案，需根据数据特性选择。

6. **Huber Loss + 自适应阈值的鲁棒训练策略**：先用简单loss warm-up估计残差分布，再据此设定Huber阈值，这种两阶段策略在处理异常值时非常实用，可直接用于我们系统中应对异常客流数据的训练。

# ST09: TraffiDent: A Dataset for Understanding the Interplay Between Traffic Dynamics and Incidents

## 基本信息
- **会议/期刊**: NeurIPS 2025 (Datasets and Benchmarks Track)
- **年份**: 2025
- **作者**: Xiaochuan Gou, Ziyue Li, Tian Lan, Junpeng Lin, Zhishuai Li, Bingyu Zhao, Chen Zhang, Di Wang, Xiangliang Zhang
- **机构**: KAUST (沙特), TU Munich (德国), 清华大学, 中科院自动化所, TU Vienna (奥地利), University of Notre Dame (美国)
- **关键词**: 交通数据集、事件数据、时空对齐、因果分析、异常交通预测、交通事件分类

## 研究问题与动机

### 核心问题
现有研究中，**交通流预测**和**交通事件分析**两个高度相关的研究方向长期分离：
- 交通流方向：使用 PEMS、METR-LA 等纯交通数据集训练深度学习模型，追求正常场景下几个百分点的精度提升
- 事件方向：仅单独研究事件本身（如事故风险推断、事故发生时间预测），缺乏与交通流的关联

### 关键Gap
1. **缺乏时空对齐的交通-事件联合数据集**：现有开源数据集要么只有交通流，要么只有事件记录，且事件数据粒度极粗（缺少坐标、绝对里程桩等精确位置信息）
2. **异常交通预测被忽视**：现有模型在常规时段表现好，但在突发事件导致的异常流量下性能未经充分验证
3. **因果关系未明**：缺乏对交通指标、道路元特征、事件三者之间因果关系的大规模实证研究
4. **车道级精细分析缺失**：已有数据集多为路段级别聚合，无法区分同一道路不同方向/车道的差异化影响

## 核心贡献

1. **首个大规模交通-事件时空对齐数据集 TraffiDent**：
   - 覆盖加州大都会区域，包含 **16,972 个交通节点**和 **870,100 条边**
   - 时间跨度：**2022-2024年完整3年**，5分钟时间粒度
   - 交通指标：流量（flow）、车道占有率（occupancy）、平均车速（speed）三通道时序
   - 事件记录：**7类事件**（NoInjure, UnknownInjure, Hazard, AnimalHazard, CarFire, Fire, 1141碰撞），共 1,441,904 条记录，与交通数据时空对齐
   - 每个节点含 **27个物理和政策级元特征**（路宽、地形、路面材料、设计限速、功能区划等）
   - **车道级（Lane-level）** 粒度，而非路段级聚合

2. **四项基准任务设计与实验**：
   - 事后交通预测（Post-incident Traffic Forecasting）
   - 基于交通指标的事件分类（Incident Classification）
   - 全局因果分析（Global Causal Analysis）
   - 局部因果分析（Local Causal Analysis）

3. **丰富的描述性分析发现**：
   - Hub节点 vs Fringe节点的事件模式差异显著
   - "Friday Mood"现象：无论Hub还是Fringe节点，周五事件数量均达峰值
   - 工作日vs周末事件分布呈现相反趋势

## 方法概述

本文主要是一个**数据集论文**，方法贡献体现在四个方面：

### 1. 数据集构建方法
- 数据来源：Caltrans Performance Measurement System (PeMS)
- 采集时间：2024年4月20日至5月10日
- 交通数据清洗：移除观测率低于50%的传感器，保留16,972个有效传感器
- 事件数据清洗：去重、过滤无绝对里程桩(Abs PM)的记录
- 邻接矩阵构建：基于OpenStreetMap开源路由引擎计算最短行驶距离（非欧氏距离），并考虑车道方向一致性，排除反向邻居

### 2. 事后交通预测
评估SOTA时空预测模型在**事件发生后不规则流量**下的表现。选取测试集中5分钟窗口内发生过事件的样本进行预测。

### 3. 事件分类
将事件分类建模为**多变量时间序列分类**任务：找到距事件最近的传感器，提取事件发生时间窗口内的三通道时序（speed, occupancy, flow），分类为"事故"、"危险"、"正常"三类。时间窗口长度取95分位数即2小时（$w=24$个5分钟间隔）。

### 4. 因果分析
- **全局因果**：使用 MM-DAG 算法学习元特征、事件、交通指标之间的有向无环图(DAG)。优化目标为：

$$\hat{C}^{(1)},...,\hat{C}^{(L)} = \arg\min_{C^{(1)},...,C^{(L)}} \sum_{l=1}^{L} \frac{1}{2N_l}\|A^{(l)} - A^{(l)}C^{(l)}\|_F^2 + \rho \sum_{l_1,l_2} s_{l_1,l_2} DCD(W^{(l_1)}, W^{(l_2)}) + \lambda \sum_{l=1}^{L} \|C^{(l)}\|_1$$

约束条件：$h(W^{(l)}) = \text{tr}(e^{W^{(l)}}) - P = 0$

- **局部因果**：使用 PCMCI+ 算法分析特定事件前后，相邻交通节点间因果依赖关系的变化

### 事件类型体系
7类事件：NoInjure（无伤亡事故）、UnknownInjure（未知伤亡）、Hazard（危险障碍，占52.2%为最多）、AnimalHazard（动物障碍）、CarFire（车辆起火）、Fire（火灾）、1141（需紧急医疗响应的碰撞）

### Hub/Fringe节点定义
- 基于邻接矩阵计算节点度数
- 度数最高的500个节点为Hub节点（繁忙交叉口/主干道）
- 度数最低的500个节点为Fringe节点（偏远支路）
- 事件匹配时排除距最近传感器超过0.05英里的样本

### 交通-事件时空对齐方法
1. 通过地理坐标（经纬度）和绝对里程桩(Abs PM)进行空间对齐
2. 将事件时间戳转换为5分钟时间槽进行时间对齐
3. 匹配同高速公路上Abs PM最近的传感器
4. 事件发生后的下一个时间槽定义为事后影响的起始点

### 元特征体系（27个）
分为5类：
- **位置特征**：经纬度、Abs PM、方向、高速公路ID
- **上下文特征**：城市、县、区
- **物理特征**：路宽、车道宽、内外肩宽、中央隔离带类型/宽度、地形、路面材料、屏障类型
- **政策特征**：设计限速、功能区划、人口类型、道路用途、HOV标识
- **传感器特征**：传感器ID、类型、道路级别（主线/匝道等）

## 实验

### 数据集
- **TraffiDent**（本文提出）：16,972节点，2022-2024年，5分钟粒度
- 事后预测子实验使用 San Bernardino 区域561个主线传感器的3个月数据
- 事件分类使用全量数据中与事件匹配的传感器时序

### 基线方法

**事后交通预测基线**：
- LSTM、ASTGCN、DCRNN、AGCRN、GWNET、STGODE、DSTAGNN、D2STGNN

**事件分类基线**：
- Decision Tree (DT)、TS2Vec、gMLP、Sequencer、OmniScaleCNN、PatchTST、FormerTime

**全局因果分析**：MM-DAG
**局部因果分析**：PCMCI+

### 主要结果

#### 事后交通预测
- 所有SOTA模型在事件后不规则流量下性能**显著下降**
- General（常规）vs Post-incident 性能差距明显，说明现有模型对突发事件引起的异常模式鲁棒性不足
- 这验证了TraffiDent作为异常交通预测评测基准的价值

#### 事件分类
- 最佳准确率约 **41.6%**（DT和PatchTST），优于随机猜测（3类→33%），证明从交通指标推断事件类型可行
- 不同通道（speed/occupancy/flow）对不同方法的贡献不同
- 多通道融合通常带来性能提升
- DT、gMLP、PatchTST统计上无显著差异，均为top performers

#### 全局因果分析
- 静态变量（路面、地形、路宽）对事件和交通状态有**一致且显著**的影响
- 动态变量（时间、天气、能见度）的因果关系较弱且因区域而异
- 具体发现：
  - 工作日早晚高峰时段Hazard概率更高
  - 降雨增加事故概率，但雨量大小对事故率影响不显著
  - 桥面和厚度>7英寸的路面Hazard概率更低
  - 平坦地形平均车速高于起伏地形

#### 局部因果分析（案例研究）
- Novato立交桥附近1141碰撞事件案例
- 事前因果图符合交通传播常识：$X_2 \to X_3 \to X_4$
- 事后因果图新增两条滞后因果链：$X_3 \xrightarrow{lag1} X_2$ 和 $X_4 \xrightarrow{lag1} X_1$
- 解释：碰撞导致$X_3$处拥堵→向上游$X_2$扩散；东出口拥堵→$X_1$到$X_4$需求减少→$X_1$处车速提高、流量增加

#### 事件信息增强预测（附录补充实验）
- 在STID模型中加入事件特征embedding
- MAE从13.11降至12.69，RMSE从23.98降至23.32
- 证明事件信息对交通预测有正向增益，但提升幅度有限

## 与本项目的关联

### 直接相关性：⭐⭐⭐⭐⭐（极高）

本项目目标是构建**节假日/极端天气场景下的异常客流预测系统**，TraffiDent论文提供了多方面的直接启发：

1. **异常场景建模思路**：本文的核心洞察——"常规模型在事件引发的异常模式下性能显著下降"——与本项目面临的节假日/极端天气异常客流问题完全一致。我们的系统需要专门针对异常场景进行设计和评测。

2. **外部因素融合范式**：本文将事件作为独立信号与交通流时空对齐的方法论可直接迁移。在我们的场景中，可将节假日日历、天气预警、大型活动信息等作为类似"事件"的外部因子，与时序数据进行对齐。

3. **因果分析方法论**：
   - 全局因果分析（MM-DAG）可用于识别哪些外部因素（节假日类型、天气等级、温度等）对客流异常的因果效应最强
   - 局部因果分析（PCMCI+）可用于理解异常事件前后，不同站点/区域间客流传播关系的变化

4. **数据集构建参考**：TraffiDent的多维度元特征体系（物理+政策）启发我们在构建客流数据集时，也应纳入站点属性（换乘站/终点站）、周边POI、历史同期节假日客流模式等元特征。

5. **评测基准设计**：本文区分General vs Post-incident性能的评测方式值得借鉴。我们应建立类似的Normal vs Anomaly分组评测，避免模型在常规时段的高精度掩盖异常时段的失效。

### 可迁移的技术点
- 时空对齐方法论（坐标+时间槽匹配）
- 事件embedding注入预测模型的策略（附录A.12的STID+Incidents实验）
- Hub/Fringe节点划分思想→可类比为核心枢纽站vs边缘站的差异化建模
- 多通道时序分类框架→可用于异常事件类型识别

## 关键启发

1. **异常是常态的对立面，需要专门对待**：不能假设在正常数据上训练的模型能自动泛化到异常场景。异常客流预测需要专门的异常样本、专门的评测指标、甚至专门的模型架构。

2. **外部事件信息的价值已被证实但有限**：简单地将事件作为embedding加入模型仅带来小幅提升（MAE降3%左右）。更有效的策略可能是：(a) 根据事件类型选择不同预测策略；(b) 利用因果关系指导特征工程；(c) 设计事件感知的注意力机制。

3. **车道级/站点级精细粒度的重要性**：同一道路不同方向的受影响程度可能截然不同。在客流场景中，同一地铁站的不同出入口、上下行方向在节假日的客流模式也可能完全不同，需要细粒度建模。

4. **因果图可作为可解释性工具**：不仅用于分析，还可用于验证模型学到的时空依赖是否合理。如果模型关注的依赖关系与因果图一致，则增加了可信度。

5. **"Friday Mood"等周期性异常模式**：提示我们在节假日预测中，不仅要关注节假日当天，还要关注节前过渡期（如节前最后一个工作日）可能出现的特殊模式。

6. **数据集论文的标杆作用**：TraffiDent展示了高质量数据集如何通过精心设计四项基准任务来展示其广泛适用性。如果我们构建异常客流数据集，也应设计类似的多样化下游任务来验证其价值。

## 研究问题与动机

### 核心问题
现有基于深度学习的时空交通预测方法**仅关注从历史交通数据中捕获时空依赖关系**，忽视了一个关键事实：突发交通事件（如交通事故、恶劣天气等）作为外部扰动会**显著改变交通流的时序模式**。这种忽视已成为建模交通系统动态和提升预测精度的主要障碍。

### 问题图示（Figure 1）
论文通过一个直观案例说明了问题：在正常场景下，模型能很好地拟合平滑的日常交通流模式；但当附近交叉口发生碰撞事故时，真实交通流量急剧下降，而传统模型的预测仍沿历史均值走，导致**巨大的预测误差**。

### 三大挑战
1. **空间域上的非均匀事件影响（Non-uniform Incident Impact on Spatial Domain）**：事件可发生在路网任意位置，即使两个事件位于同一对传感器之间，不同传感器因距事故点距离不同也会感知到不同程度的影响。
2. **影响的动态时间演化（Dynamic Temporal Evolution of Impact）**：事件的影响不是单一的静态脉冲，而是随时间演化的动态过程。未能建模这种时间衰减是长期预测严重误差的主要原因。
3. **事件信息的多样性与复杂性（Diversity and Complexity of Incident Information）**：事件性质多样（多车碰撞 vs 车辆抛锚），每种类型对交通流的影响独特；且单个事件的描述数据本身是多模态、非结构化的。

### 核心洞察
当模型仅在混合了正常和异常时段的数据上训练时，其优化过程被迫学习一个**折中函数**——代表正常和异常模式的平均，从而抹平了事件引起的尖锐动态变化。这导致模型在遇到突发事件时性能严重退化。

## 核心贡献

1. **提出IGSTGNN框架**：首个专门针对事件影响进行显式建模的时空预测框架，不再仅从历史交通模式中学习，而是显式建模由外部事件引发的独特时空动态。

2. **两个核心模块设计**：
   - **ICSF（Incident-Context Spatial Fusion）模块**：捕获事件初始的、非均匀的空间影响
   - **TID（Temporal Incident Impact Decay）模块**：建模事件影响随时间的动态消散过程

3. **构建并发布大规模数据集**：基于XTraffic基准数据集构建了三个子数据集（Alameda、Contra Costa、Orange），包含与交通时序时间对齐的事件记录。在该基准上，IGSTGNN达到SOTA性能。

4. **即插即用验证**：ICSF和TID模块可作为通用增强组件集成到多种现有STGNN模型中，一致性地提升其性能。

## 方法概述

IGSTGNN采用三阶段流水线架构：

### 整体流程
$$\hat{Y} = \mathcal{F}(X, S_{raw}, E_{raw}, D, G, \Theta)$$

其中 $X$ 为历史交通状态，$S_{raw}$ 为传感器静态属性，$E_{raw}$ 为事件信息，$D$ 为事件-传感器空间关系张量，$G$ 为路网图，$\Theta$ 为可学习参数。

### 阶段一：特征编码（Feature Encoder）
- 传感器语义属性 $s_{i,f}$ → 编码为 $S \in \mathbb{R}^{N \times d_s}$
- 事件内在+上下文属性 $e_{i,i}, e_{i,c}$ → 编码为 $I \in \mathbb{R}^{M_e \times d_e}$
- 交通时序 $X$ → 线性投影为隐状态 $H \in \mathbb{R}^{T \times N \times d_h}$

### 阶段二：事件-上下文空间融合（ICSF Module）
将事件信息注入到交通表示中，生成事件感知的隐状态表示。

### 阶段三：时空依赖建模（ST Dependency Modeling）
使用解耦架构分别捕获：(a) 从邻居节点传播的外部影响；(b) 节点自身的内在时序演化趋势。

### 阶段四：时间事件影响衰减（TID Module）
显式建模事件影响在预测时域内的衰减过程，叠加到基础预测之上生成最终结果。

## 关键技术细节

### 1. 事件-传感器空间关系张量 $D$

预定义张量 $D \in \mathbb{R}^{M_e \times N \times 3}$，从三个互补角度刻画事件与传感器的空间关系：
- **路网距离**：捕获沿直接道路连接的线性传播影响
- **欧氏距离**：捕获对地理邻近区域的"溢出"效应
- **上下游关系**：区分上游交通的严重影响与下游交通的通常可忽略影响

对于每个事件-传感器对 $(e_k, v_j)$，三维向量的前两个分量通过高斯核计算接近度得分，第三个分量为二元指示器（若事件的Abs PM大于传感器的则为1，否则为0）。

### 2. ICSF模块详解

**注意力投影**：
$$Q = H_t W_Q, \quad K = I W_K, \quad V = I W_V$$

其中 $Q \in \mathbb{R}^{N \times d_k}$ 表示各传感器当前状态，$K \in \mathbb{R}^{M_e \times d_k}$ 表示事件匹配属性，$V \in \mathbb{R}^{M_e \times d_v}$ 包含待聚合的事件信息。

**语义相关性评分**：
$$A_{sem} = \frac{QK^T}{\sqrt{d_k}}$$

**拓扑掩码**：强制只有与事件有拓扑连接的节点才能接收影响：
$$(A'_{sem})_{kj} = \begin{cases} (A_{sem})_{kj} & \text{if } (e_k, v_j) \text{ are connected in } D \\ -\infty & \text{otherwise} \end{cases}$$

**初步注意力权重**：
$$\tilde{\alpha} = \text{softmax}(A'_{sem})$$

**最终上下文感知注意力**（融合传感器特征和空间关系）：
$$\alpha = \text{softmax}(g_a(\tilde{\alpha} \| S \| D))$$

其中 $g_a$ 为MLP融合函数，$\|$ 表示拼接操作。

**加权聚合与残差融合**：
$$C = \alpha^T V, \quad H'_t = \text{LayerNorm}(H_t + C)$$

### 3. 时空依赖建模（解耦架构）

采用三种邻接矩阵的多图卷积：
- **静态邻接矩阵** $A$：固定物理路网结构
- **自适应邻接矩阵** $A_{ada} = \text{softmax}(\text{ReLU}(E_1 E_2^T))$：潜在静态空间依赖
- **动态邻接矩阵** $A_{dyn}$：随时间变化的瞬态空间相关性

$$A_{dyn} = \text{softmax}\left(\frac{(E_{dyn}W_1)(E_{dyn}W_2)^T}{\sqrt{d_{dyn}}}\right)$$

每个解耦块的操作：
1. **外部影响分量**：多图卷积 $g_s$ 捕获传播的空间影响 → $H^{(l)}_{ext}$
2. **残差提取内在趋势**：$H^{(l)}_{int} = H^{(l)} - H^{(l)}_{ext}$
3. **内在趋势分量**：RNN + Self-Attention处理残差表示 → 精炼趋势 $H^{(l)}_{trend}$
4. **输出**：$H^{(l+1)} = H^{(l)}_{int} - H^{(l)}_{trend}$

经过 $L$ 层迭代后，累积各层两个分量的预测部分得到 $H_{pred}$。

### 4. TID模块详解

**初始事件上下文**：
$$C_{init} = g_c(K_{context} \| S \| D)$$

其中 $K_{context}$ 是经空间掩码后的局部化事件表示。

**时间衰减因子**（高斯函数）：
$$\omega_t = \exp\left(-\frac{t^2}{2\sigma^2}\right)$$

其中 $\sigma$ 控制衰减速率（实验中设为1.0）。

**时间事件影响张量**：
$$C_{temp} = \omega \odot (C_{init} W_c)$$

其中 $\odot$ 表示广播乘法。

**最终预测**：
$$\hat{Y} = g_{out}(H_{pred} + C_{temp})$$

### 5. 问题定义的关键假设
> "很久以前发生的事件的影响已经隐含在近期历史交通数据中。但在最近时间步 $t$ 新发生的事件，其完整影响尚未在网络中传播，也未反映在历史序列中。"

因此，任务特别聚焦于**显式建模新发生事件的影响**来预测未来交通状态。

## 实验

### 数据集
基于XTraffic基准数据集（加州2023年数据），选取主线传感器，5分钟粒度，构建三个子数据集：

| 数据集 | 节点数 | 边数 | 事件数 |
|--------|--------|------|--------|
| Alameda | 521 | 13,828 | 14,687 |
| Contra Costa | 496 | 13,339 | 5,587 |
| Orange | 990 | 29,142 | 18,700 |

- 任务设置：用过去1小时（12步）预测未来1小时（12步）
- 划分比例：训练/验证/测试 = 70%/15%/15%

**传感器元特征**（9类）：Type、Surface、Roadway Use、Lane Width、Design Speed Limit、Latitude/Longitude、Freeway Name、Absolute Postmile

**事件信息特征**（8类）：Relative Position、Description、Type、Holiday、Latitude/Longitude、Absolute Postmile、Freeway Name

### 基线方法
- **经典方法**：HL（Historical Average）、LSTM
- **RNN-based**：DCRNN、AGCRN
- **CNN-based**：STGCN、GWNET
- **Attention-based**：ASTGCN、STTN
- **Dynamic Graph-based**：DSTAGNN、DGCRN、D²STGNN、BiST

### 主要结果

#### 总体性能对比（Table 4）
IGSTGNN在所有数据集和所有预测时域上一致优于所有基线：

| 数据集 | 指标 | IGSTGNN | 次优模型 | 提升幅度 |
|--------|------|---------|----------|----------|
| Alameda | Avg MAE | **12.69** | 13.45 (BiST) | 5.65% |
| Contra Costa | Avg MAE | **13.43** | 14.09 (D²STGNN) | 4.68% |
| Orange | Avg MAE | **13.13** | 13.82 (STTN) | 5.00% |

#### 关键观察
1. **长期预测鲁棒性**：在最具挑战性的Horizon 12（60分钟）上，IGSTGNN仍保持显著优势（Orange数据集MAE领先4.1%），直接验证了TID模块在捕获交通恢复动态方面的有效性。
2. **空间异质性适应性**：在三个具有不同路网结构和事件分布的数据集上均保持领先，说明ICSF模块能有效处理事件影响的空间异质性。

#### 模块有效性验证（Figure 3）
将ICSF和TID作为即插即用组件集成到四种不同架构的基线模型中：

| 基线模型 | 架构类型 | +ICSF | +TID | +BOTH |
|----------|----------|-------|------|-------|
| AGCRN | RNN-based | ✓ | ✓ | ✓✓ |
| GWNET | CNN-based | ✓ | ✓ | ✓✓ |
| STTN | Attention-based | ✓ | ✓ | ✓✓ |
| D²STGNN | Decoupling hybrid | ✓ (+8.85%) | ✓ (+9.85%) | ✓✓ (+13.23%) |

- 单独集成任一模块均带来一致性提升
- 同时集成两个模块的提升最为显著，展示了强协同效应
- D²STGNN + BOTH 的MAE提升达13.23%，远超单独使用之和

#### ICSF优越性验证（Figure 4）
对比两种替代融合方案：
- **MLP**：简单拼接所有信息后通过MLP融合
- **IMP**（Iterative Message Passing）：多轮交互式消息传递更新

ICSF在Alameda上的MAE比MLP低10.3%，比IMP低12.5%。证明注意力机制在捕获关键信息和建模复杂关系之间取得了更好的平衡。

#### 消融实验（Table 5）

| 变体 | Alameda MAE | Contra Costa MAE | Orange MAE |
|------|-------------|------------------|------------|
| w/o ICSF | 13.23 (+4.2%) | 13.52 | 13.38 |
| w/o TID | 13.23 (+4.2%) | 13.54 | 13.32 |
| w/o Sensor Attr. | 13.21 | 13.52 | 13.45 |

关键发现：
- ICSF和TID均有稳定贡献，移除任一模块MAE增加约4%
- 事件属性（类型、描述）提供超越空间邻近度和传感器上下文的额外判别线索
- 距离信息对建模事件影响在交通图中的传播至关重要（Orange上移除后MAPE升至17.50%）

### 实现细节
- 优化器：Adam，初始学习率0.002
- Early Stopping：patience=20 epochs
- Batch Size：Alameda/Contra Costa=48，Orange=24
- 事件类型embedding：6种类型→8维；30种描述→32维
- ST模块：5个解耦块，自适应节点和时间戳embedding维度=12
- TID衰减参数 $\sigma = 1.0$
- 硬件：Intel Xeon Gold 6138 CPU + NVIDIA Tesla V100 (32GB)

## 与本项目的关联

### 直接相关性：⭐⭐⭐⭐⭐（极高）

本项目目标是构建**节假日/极端天气场景下的异常客流预测系统**，IGSTGNN的设计思路提供了高度直接的参考价值：

1. **异常事件驱动的预测范式**：本文的核心论点——"不能仅从历史模式中学习，必须显式建模外部扰动的影响"——与本项目面临的节假日/极端天气异常客流问题完全对应。在我们的场景中，节假日和极端天气就是"事件"，需要类似的显式建模而非期望模型从混合数据中自动学习。

2. **ICSF模块的直接迁移**：
   - 将"事件"替换为"节假日/天气预警/大型活动"等外部因子
   - 注意力机制中的拓扑掩码可替换为站点间的OD关联或换乘关系掩码
   - 传感器元特征可替换为站点属性（换乘站/终点站、周边POI密度、历史同期客流基线等）
   - 空间关系张量 $D$ 的三个维度可调整为：OD距离、线路连接距离、上下游方向关系

3. **TID模块的适配改造**：
   - 交通事件的影响是高斯衰减的，但节假日客流的影响模式可能更复杂（如节前攀升→节中高峰→节后回落的非对称模式）
   - 可将高斯衰减替换为参数化的非对称衰减函数，或基于历史同期模式学习的衰减曲线
   - 极端天气的影响衰减可能与天气持续时间、强度变化相关，需要条件化的衰减建模

4. **数据集构建方法论**：本文基于XTraffic构建子数据集的方法可直接参考。我们也需要将节假日日历、天气预报、大型活动信息等与客流数据进行精确的时间对齐，并标注事件类型和严重程度。

5. **评测策略借鉴**：本文区分常规vs事件场景的性能评测方式值得采纳。我们应建立Normal Day vs Holiday vs Extreme Weather的分组评测体系。

### 可迁移的技术点
- 事件-传感器空间关系张量的多维建模思想 → 事件-站点关系张量
- 拓扑掩码约束注意力权重的设计 → 避免不相关站点受到虚假影响
- 即插即用的模块化设计理念 → 可在现有客流预测backbone上增量添加事件感知能力
- 解耦外部影响与内在趋势的ST建模思路 → 分离节假日效应与日常通勤模式
- 高斯时间衰减函数 → 可扩展为多种衰减模式的混合

### 与ST09(TraffiDent)的关系
本文使用的XTraffic数据集与ST09(TraffiDent)论文的PeMS数据来自同一数据源体系（加州交通数据），但本文更侧重于**预测模型设计**，而ST09侧重于**数据集构建与分析**。两篇论文互为补充：ST09揭示了"常规模型在事件后性能显著下降"的问题，本文则提出了系统性解决方案。

## 关键启发

1. **"显式建模"优于"隐式学习"**：不要期望深度学习模型能从混合数据中自动学到异常模式。对于已知的、可标记的外部扰动（节假日、极端天气），应将其作为独立信号显式注入模型。这与本项目"异常客流需要专门对待"的设计理念高度一致。

2. **空间异质性是关键**：同一事件对不同节点的影响程度差异巨大，取决于距离、拓扑关系、区域特征。在客流场景中，同一个节假日对不同站点（景区站、商务站、交通枢纽站）的影响也截然不同，需要细粒度的个性化建模。ICSF的注意力+掩码+融合三层设计值得借鉴。

3. **时间衰减不可忽视**：事件影响不是瞬时脉冲，而是一个有明确时间结构的动态过程。在节假日场景中，这种时间结构更加丰富（预热期、高峰期、回落期），需要更精细的参数化建模。TID模块的高斯衰减是一个优雅的起点，但需要根据实际场景扩展。

4. **模块化设计的工程价值**：ICSF和TID被设计为即插即用组件，可以增强任何现有STGNN。这对本项目的工程实践非常有价值——我们可以在已有的客流预测模型基础上增量添加事件感知模块，而不必从头重新设计整个系统。

5. **多源异构特征的融合需要精心设计**：简单的拼接融合（MLP）效果最差，过度复杂的交互（IMP）也难以优化。基于注意力的、带有领域知识约束（拓扑掩码）的融合方案是最优选择。这提示我们在融合节假日/天气/活动等异构信息时，也应引入合理的归纳偏置。

6. **新事件vs历史事件的区分处理**：论文的关键假设——"旧事件影响已在历史数据中，只需显式建模新事件"——提供了一个实用的工程简化。在我们的场景中，可以将"即将到来的节假日"视为"新事件"进行显式建模，而过去节假日的影响已通过历史客流数据隐式捕获。

7. **数据集是研究的基石**：本文不仅提出模型，还构建并发布了专用数据集。这提醒我们，要推动异常客流预测的研究和实践，首先需要构建高质量的、包含外部事件标注的客流数据集。

# ST11: Towards Resilient Transportation: A Conditional Transformer for Accident-Informed Traffic Forecasting

## 基本信息
- **会议/期刊**: KDD '26 (The 32nd ACM SIGKDD Conference on Knowledge Discovery and Data Mining)
- **年份**: 2026
- **作者**: Hongjun Wang, Jiawei Yong, Jiawei Wang, Shintaro Fukushima, Renhe Jiang*（东京大学 & 丰田汽车）
- **关键词**: Spatio-temporal forecasting, Traffic accident, Urban computing, Conditional Transformer, Guided Layer Normalization
- **代码**: https://github.com/Dreamzz5/ConFormer

## 研究问题与动机

### 核心问题
交通预测在正常模式下已有较好表现，但**交通事故等突发事件导致的异常交通模式**仍是关键挑战。现有模型在事故发生时性能显著下降。

### 动机分析
1. **正常 vs 异常的根本矛盾**：正常交通遵循可预测的时间规律（如早晚高峰），现有模型（如 DCRNN）可以很好捕获；但事故造成的扰动以非线性方式在网络中传播，导致速度骤降和复杂变化，当前时空方法无法有效建模。
2. **事故数据覆盖不足**：大多数交通数据集缺乏详细的事故信息，仅有基础流量数据，阻碍了系统研究事故和管制对交通模式的影响。
3. **事故建模能力不足**：现有方法要么完全忽略事故因素，要么仅将其作为外部特征简单拼接，未能考虑事故如何改变空间关系、时间依赖和数据分布。
4. **实际影响量化**：研究表明事故可使出行时间增加 37%-43%（FHWA 数据），高速公路事故是非经常性拥堵的主要原因。

> **与本项目的直接关联**：本项目关注节假日/极端天气下的异常客流预测，与本文关注的事故场景同属"异常事件驱动的时空预测"范畴，核心矛盾一致——常规模型擅长规律性模式，但在外部事件冲击下失效。

## 核心贡献

1. **ConFormer 模型**：提出条件 Transformer 架构，采用 **Guided Layer Normalization (GLN)** 机制，根据交通条件动态调整归一化参数，自适应捕获时空动态并感知事故信息。
2. **两个大规模数据集**：
   - **Tokyo 高速公路数据集**：1,843 条路段，含 JARTIC 权威事故与管制数据（10 分钟粒度）
   - **California 数据集**：Bay Area（2,352 传感器）+ San Diego（716 传感器），整合 US Accidents 数据库的事故标注
3. **SOTA 性能**：在所有数据集上超越 STAEFormer 等主流方法，同时参数量更少（~684K-784K vs STAEFormer 的 1.7M-18M）、计算开销更低。

## 方法概述

ConFormer 的整体架构包含两条并行分支：

```
输入 X → 嵌入层(含事故/管制/时间嵌入) → ┬→ 条件分支: Graph Propagation → MLP → [γ, β, α]
                                          └→ Transformer 分支: GLN + Condition Self-Attention + 条件残差连接
```

### 核心思想
将事故/管制等外部事件信息通过**图传播**生成上下文条件表示 $X^c$，再用该条件表示生成**动态仿射变换参数** $(\gamma, \beta, \alpha)$，分别控制：
- $\gamma, \beta$：LayerNorm 的动态缩放和平移（替代传统固定的 $\gamma, \beta$）
- $\alpha$：残差连接的调制因子（类似课程学习，逐步引入条件信号）

## 关键技术细节

### 1. 数据嵌入与条件注入
$$X^e = \text{MLP}(X^{data} \| X^{acc} \| X^{reg} \| X^{dow} \| X^{tod} \| X^{stae})$$

其中 $X^{acc} \in \mathbb{R}^{T \times N \times D_{acc}}$ 和 $X^{reg} \in \mathbb{R}^{T \times N \times D_{reg}}$ 分别为事故和管制的指示特征嵌入。

### 2. 图传播（Graph Propagation）
简化 GCN，仅保留图传播部分（去掉特征混合矩阵 $W$），用于建模事故影响的传播效应：
$$X^c = \text{GraphPropagation}(X^e, A) = [X^e \| \tilde{L}X^e \| \tilde{L}^2 X^e \| \dots \| \tilde{L}^K X^e]$$

其中 $\tilde{L}$ 为归一化图拉普拉斯矩阵，$K$ 为切比雪夫多项式阶数（实验中 $k=1\text{-}2$ 即可）。

### 3. Guided Layer Normalization (GLN) ⭐核心创新
传统 LayerNorm：
$$\text{LN}(X) = \gamma \cdot \frac{X - \mu}{\sigma} + \beta$$
其中 $\gamma, \beta$ 是**固定的**可学习参数。

GLN 将 $\gamma, \beta$ 替换为从条件表示 $X^c$ 动态生成的参数：
$$\gamma, \beta = \text{MLP}(X^c)$$
$$\text{GLN}(X, \gamma, \beta) = \gamma \cdot \frac{X - \mu}{\sigma} + \beta$$

**理论解释**：GLN 等价于对 self-attention 中的 Q, K 进行条件化的仿射变换：
$$\text{Softmax}\left(\frac{\gamma^2 Q'K'^T + \gamma K'\beta^T + \gamma Q'\beta^T + \beta^2}{\sqrt{d}}\right)$$

- **$\gamma$（缩放因子）**：高值 → 增强对突发变化的敏感度，快速适应事故；低值 → 抑制局部波动，保持常规稳定性
- **$\beta$（平移因子）**：高值 → 强调节点特异性特征，增强事故响应中的局部表示；低值 → 保持全局一致性

### 4. Condition Self-Attention
将归一化后的输入与条件表示拼接后计算 Q, K, V：
$$Q = X^{(N)} W_Q, \quad K = (X^{(N)} \| X^c) W_K, \quad V = (X^{(N)} \| X^c) W_V$$

使注意力机制同时感知原始特征和事故条件信息。

### 5. 条件残差连接
$$X^{(Res)} = X^{(in)} + \alpha \cdot X^{(out)}$$

其中 $\alpha = \text{MLP}(X^c)$，零初始化策略确保训练初期模型先学习基本时空模式，再逐步融入条件信号（类似课程学习）。

### 6. 计算复杂度
$$\text{FLOPs} = K|\mathcal{E}|D + (TN^2D + NT^2D) + NTD^2$$

仅需单层注意力即可达到优越性能，总参数量远低于 STAEFormer。

## 与本项目的关联

### 高度相关的方面
1. **问题定义一致**：本项目关注节假日/极端天气下的异常客流预测，与本文的事故场景本质相同——都是**外部事件驱动的非常规时空模式预测**。可将节假日/极端天气类比为"事故"，作为条件信号注入模型。
2. **GLN 机制的直接借鉴价值**：Guided Layer Normalization 是一种通用的条件化归一化方法，不局限于交通事故。对于本项目，可以将节假日类型、天气等级、大型活动信息等作为条件特征，通过 GLN 动态调整模型内部表示。**这是一个轻量级且高效的改进点**。
3. **图传播建模事件扩散**：事故影响通过路网传播，类似地，节假日客流冲击会通过地铁/公交网络传播。Graph Propagation 模块可直接用于建模异常客流的网络扩散效应。
4. **数据集构建思路**：本文整合多源异构数据（交通流 + 事故 + 管制）的方式，对本项目整合客流数据 + 节假日日历 + 气象数据有直接参考价值。
5. **条件残差连接的课程学习思想**：先学常规模式再逐步融入异常条件信号的渐进式学习策略，对处理异常样本稀缺问题很有启发。

### 需要注意的差异
1. **数据类型**：本文为道路交通流（连续值），本项目为客流量（离散计数），损失函数和数据预处理需调整
2. **事件性质**：交通事故是局部、突发的；节假日/天气影响通常是全局性、可预见的，条件特征的构造方式需相应调整
3. **图的规模**：本文处理数百到数千节点，本项目地铁站点规模可能更小但拓扑更复杂

## 关键启发

1. **"条件化"是处理异常场景的高效范式**：不需要为异常场景设计单独的模型，而是通过条件机制让同一模型自适应切换行为模式。GLN 的实现非常轻量（仅额外一个 MLP），但效果显著。
2. **归一化层的动态化是被低估的改进方向**：传统深度学习模型的 LayerNorm/BatchNorm 参数是全局固定的，但在时空数据中不同节点、不同时刻的统计特性差异巨大。GLN 证明了动态归一化的有效性，这一思路可推广到其他时空模型中。
3. **简化设计反而更有效**：ConFormer 仅用单层注意力 + 简化的图传播（去掉特征混合），就超越了复杂的 STAEFormer。说明在条件信息充分的情况下，模型不需要过深的架构。
4. **事件信息的显式注入至关重要**：消融实验清楚表明，即使在模型结构不变的情况下，有无事故数据的性能差距可达 20%+。这强调了在本项目中收集和整合节假日/天气等外部事件数据的重要性。
5. **GLN 具有良好的可插拔性**：论文验证了 GLN 可以直接应用到 GWNet 等其他模型上并取得提升，说明它是一种通用的增强组件，值得在本项目的基线模型中尝试。

# ST12: CAMEF: Causal-Augmented Multi-Modality Event-Driven Financial Forecasting by Integrating Time Series Patterns and Salient Macroeconomic Announcements

## 基本信息
- **会议/期刊**: KDD '25 (31st ACM SIGKDD Conference on Knowledge Discovery and Data Mining)
- **年份**: 2025
- **作者**: Yang Zhang, Wenbo Yang, Jun Wang, Qiang Ma, Jie Xiong（西南财经大学 & 京都工艺纤维大学）
- **关键词**: Multimodal learning, Causal Learning, Financial dataset, Time-series Forecasting, Counterfactual Augmentation, LLM

## 研究问题与动机

**核心问题**：如何准确预测显著宏观经济事件（如货币政策决议、就业报告等）对金融市场的影响？

**现有方法的三大局限性**：

1. **数据局限（Data Limitation）**：现有方法大多聚焦于单一事件类型（如FOMC会议），忽略了其他关键宏观经济事件（失业救济申请、CPI、PPI、GDP等）；且多使用日频数据，无法满足实时交易中高频数据的需求。
2. **模态局限（Modality Limitation）**：多数研究依赖单一模态——要么纯文本分析（情感分类），要么纯时间序列建模（回归预测），未能整合两种模态的互补优势。已有多模态方法缺乏有效的特征融合机制和因果学习。
3. **因果性局限（Causality Limitation）**：现有方法未纳入因果推理框架，忽略了"事件→市场反应"之间的因果关系，导致模型无法充分捕捉金融市场行为的驱动因素，限制了预测鲁棒性。

**动机示例**：2020年3月16日FOMC紧急降息至0-0.25%，S&P 500、NASDAQ、道琼斯单日暴跌超10%，为1987年以来最大单日跌幅。这类事件与市场波动之间存在明确的因果关系。

## 核心贡献

1. **新颖数据集**：构建了首个整合政策文本、高频交易数据和因果增强内容的开源合成数据集。包含6类宏观经济事件脚本（2008年至2024年4月），以及5个关键美国金融资产（SPX、INDU、NDX、USGG1M、USGG5YR）的5分钟级高频交易数据。还通过LLM生成反事实事件脚本用于因果学习。
2. **新颖多模态模型CAMEF**：提出整合时间序列与文本特征的多模态框架，包含专门设计的多特征融合网络、时间序列解码机制和因果学习策略。
3. **反事实生成与因果学习**：提出基于LLM的反事实数据增强策略，通过修改关键数值和情感相关短语生成不同情感水平的反事实事件脚本，同时保持原始格式和中性内容不变。结合Triplet Loss进行因果对比学习。

## 方法概述

CAMEF架构由四个核心组件构成：

```
┌─────────────────┐    ┌──────────────────┐
│ Textual Encoder  │    │ Time-Series      │
│ (RoBERTa +      │    │ Encoder          │
│  Projection)     │    │ (MOMENT +        │
│                  │    │  Multi-Residual) │
└────────┬────────┘    └────────┬─────────┘
         │                      │
         └──────────┬───────────┘
                    ▼
         ┌─────────────────────┐
         │ Feature Fusion      │
         │ (Concat + FFN)      │
         └──────────┬──────────┘
                    ▼
         ┌─────────────────────┐
         │ GPT-2 Decoder       │
         │ (Auto-regressive)   │
         └──────────┬──────────┘
                    ▼
         ┌─────────────────────┐
         │ Post-Regressor      │
         │ (Linear + GELU +    │
         │  Dropout)           │
         └──────────┬──────────┘
                    ▼
              Predictions Ŷ
```

训练目标为两部分之和：$\mathcal{L}_{\text{Total}} = \mathcal{L}_{\text{Time}} + \mathcal{L}_{\text{Causal-TL}}$

## 关键技术细节

### 1. 文本模态编码器（CAMEF_Textual）
- 使用RoBERTa编码事件脚本 $E_i = \{w_1, w_2, \ldots, w_m\}$，得到上下文token嵌入 $\{h_1, h_2, \ldots, h_m\}$，其中 $h_j \in \mathbb{R}^{1 \times 768}$
- 每个嵌入经过三层线性投影网络（含GELU激活）：
  $$e_j = W^{(3)} \cdot \text{GELU}(W^{(2)} \cdot \text{GELU}(W^{(1)} h_j + b^{(1)}) + b^{(2)}) + b^{(3)}$$
  其中 $W^{(1)} \in \mathbb{R}^{768 \times 1024}$, $W^{(2)} \in \mathbb{R}^{1024 \times 1024}$, $W^{(3)} \in \mathbb{R}^{1024 \times 768}$
- 最终文本编码向量为所有变换后嵌入的平均值：$\mathbf{E}_i = \frac{1}{m}\sum_{j=1}^{m} e_j$

### 2. 时间序列模态编码器（CAMEF_Time-Series）
- 使用预训练的MOMENT模型编码时间序列段：$\mathbf{X}_i = \text{MOMENT}(\{X_1, X_2, \ldots, X_n\})$，$\mathbf{X}_i \in \mathbb{R}^d$
- 引入多残差投影层增强表示：
  $$Z_i = \mathbf{X}_i + f_{\text{residual}}(\mathbf{X}_i)$$
  其中 $f_{\text{residual}}$ 由多层线性层+GELU组成，$W_1, W_2 \in \mathbb{R}^{1024 \times 1024}$, $W_3 \in \mathbb{R}^{1024 \times 768}$

### 3. 特征融合与解码
- 拼接两种模态编码：$\mathbf{E}_{\text{combined}} = \text{Concat}(\mathbf{E}_i, Z_i)$
- 通过两层前馈网络融合：$\mathbf{E}_{\text{fused}} = W^{(f2)} \cdot \text{GELU}(W^{(f1)} \cdot \mathbf{E}_{\text{combined}} + b^{(f1)}) + b^{(f2)}$
- 使用GPT-2（12层）作为自回归解码器：$H^{(l)} = f^{(l)}_{\text{GPT2\_layer}}(H^{(l-1)})$，其中 $H^{(0)} = \mathbf{E}_{\text{fused}}$
- 输出经LayerNorm后送入Post-Regressor（4层线性+GELU+Dropout(0.1)）生成预测 $\hat{Y}$

### 4. 时间序列预测损失
$$\mathcal{L}_{\text{MSE}} = \frac{1}{n}\sum_{i=1}^{n}(\hat{Y}_i - Y_i)^2, \quad \mathcal{L}_{\text{MAE}} = \frac{1}{n}\sum_{i=1}^{n}|\hat{Y}_i - Y_i|$$
$$\mathcal{L}_{\text{Time}} = \mathcal{L}_{\text{MSE}} + \mathcal{L}_{\text{MAE}}$$

### 5. 反事实事件生成（LLM-based）
- 形式化定义：给定事件脚本 $E_i = E^{\text{neutral}}_i \cup E^{\text{sentiment}}_i$，生成反事实版本：
  $$E'_i = E^{\text{neutral}}_i \cup f_{\text{LLM}}(E^{\text{sentiment}}_i | S'_i)$$
- 使用LLaMA-3 8B模型，三步提示策略：
  1. **摘要提示**：将长事件脚本压缩为简洁摘要，保留关键数值变量
  2. **情感分析提示**：对原始脚本打分（1-10分），提供基准
  3. **反事实生成提示**：修改情感相关短语和数值，生成不同情感水平的反事实版本，保持中性内容和格式不变

### 6. 多样化反事实采样机制
两类反事实事件：
- **同类型采样（Identical Type Sampling）**：同类型事件的反事实版本（修改情感和数值），默认10个
- **多样类型采样（Diverse Type Sampling）**：用日期最近的5种其他类型事件替换

### 7. 因果学习目标（Triplet Loss）
- 文本编码器分别编码真实事件 $E_{GT}$ 和反事实事件 $E_{CF}$
- 时间序列编码器编码历史时间序列段得到嵌入 $T$
- Triplet Loss确保真实事件嵌入比反事实事件嵌入更接近时间序列嵌入：
  $$\mathcal{L}_{\text{Causal-TL}} = \max(0, \ d(P_{GT}, T) - d(P_{CF_i}, T) + \alpha)$$
  其中margin $\alpha = 1.0$

### 8. 两阶段训练策略
- **阶段一**：预训练MOMENT模型学习时间序列表示
- **阶段二**：训练完整CAMEF模型。冻结MOMENT全部参数、RoBERTa（除最后一层）、GPT-2 token嵌入层；其余组件可训练
- 各组件采用差异化学习率（MOMENT: $1\times10^{-6}$, RoBERTa: $5\times10^{-7}$, GPT2: $1\times10^{-5}$等）

## 实验

### 数据集
- **宏观事件数据**：6类事件（FOMC会议纪要、失业救济申请、就业情况报告、GDP先行报告、CPI报告、PPI报告），覆盖2008-2024年，共计约2,569个事实事件 + 22,660个反事实事件
- **时间序列数据**：5个金融资产（S&P500、道琼斯工业指数、NASDAQ、美国1个月国债、美国5年期国债），5分钟级高频数据，数据点从75万到33万不等
- **划分比例**：训练集:验证集:测试集 = 6:2:2

### 基线方法
- **单模态基线**：ARIMA, DLinear, AutoFormer, FEDformer, iTransformer, PatchTST
- **多模态基线**：TEST (ICLR 2024), GPT4MTS (AAAI 2024)

### 主要结果
- CAMEF在30个实验设置中**24个排名第一**，其余6个排名第二
- 相比最佳单模态模型iTransformer，CAMEF平均MSE降低**62.55%**
- 相比最佳多模态模型TEST，CAMEF平均MSE降低**33.55%**
- 在股票市场指数（SPX、INDU、NDX）上全面最优（除INDU短期预测外）
- 在1个月国债（USGG1M）上全面最优；5年期国债（USGG5YR）排第二（长期国债可能对事件驱动因素敏感度较低）

### 消融实验关键发现
1. **全模型最优**：移除任何组件均导致性能下降，验证了多模态融合的必要性
2. **因果学习的增量价值**：移除因果学习后性能下降，确认其在捕获因果关系中的作用
3. **GPT-2解码器和特征融合的关键作用**：移除后某些资产（如INDU、USGG1M）性能急剧恶化
4. **Post-Regressor不可或缺**：移除后平均MSE大幅上升

### 事件类型分析（S&P500）
- **FOMC会议纪要**预测效果最好（MSE/MAE最低），确认其最关键的市场影响力
- **失业救济申请**和**就业情况报告**也有较好预测效果
- **CPI和PPI报告**预测能力较弱，PPI误差最高

### 超参数敏感性
- 反事实样本数量 $\alpha$：增加到10左右性能饱和
- Post-Regressor深度 $k$：$k=4$ 后收益递减

## 与本项目的关联

本项目关注**节假日/极端天气场景下的异常客流预测**，与CAMEF有以下关联点和可借鉴之处：

1. **事件驱动预测范式的高度相似性**：CAMEF解决的是"宏观事件→金融市场反应"的因果预测问题，本项目解决的是"节假日/极端天气事件→客流异常"的预测问题。两者本质上都是**外部事件驱动的时序异常预测**。CAMEF将事件文本与历史时序对齐的方式（$[X_{i-\tau:i+\tau} \mapsto E_i]$）可直接迁移到本项目的"事件-客流"对齐建模中。

2. **多模态融合思路**：CAMEF融合文本模态（事件描述）和时间序列模态（历史价格）的方法对本项目有直接参考价值。本项目可类似地融合：
   - 文本/结构化信息：节假日类型、天气预报文本、预警等级等
   - 时间序列：历史客流数据、天气数值数据等

3. **因果学习与反事实增强的启发**：CAMEF通过LLM生成反事实事件来增强因果理解的做法非常有启发性。在本项目中，可以：
   - 生成反事实场景（如"如果没有暴雨预警，客流会如何？""如果春节提前一周，客流模式如何变化？"）
   - 通过对比真实与反事实场景，让模型更好地区分"事件导致的异常"与"自然波动"

4. **高频数据的处理经验**：CAMEF使用5分钟级高频金融数据，其时间序列编码器（MOMENT + 多残差层）和解码器（GPT-2自回归）的设计可为本项目处理高频客流数据提供参考。

5. **事件重要性分析的参考**：CAMEF发现FOMC和失业相关事件对市场影响最大。类似地，本项目可通过消融实验分析不同类型事件（春节vs国庆vs台风vs暴雪等）对客流异常的预测贡献度。

## 关键启发

1. **因果关系建模是事件驱动预测的核心**：单纯的相关性学习不够，需要显式建模"事件→结果"的因果链。Triplet Loss + 反事实对比是一种实用的因果学习手段。

2. **LLM作为反事实数据生成器的创新用法**：利用LLM的语言理解和生成能力，系统性地创建"假设性场景"，这在数据稀缺的异常事件预测中尤其有价值。对于本项目中罕见的极端天气事件，同样可以用LLM生成多样化的反事实/增强样本。

3. **预训练模型的组合策略值得借鉴**：CAMEF组合了三个预训练模型（RoBERTa + MOMENT + GPT-2），各自负责一个子任务，并通过选择性冻结实现高效微调。这种"预训练组件拼装+差异化学习率"的策略适合资源有限的场景。

4. **特征融合设计的重要性**：简单的concat + FFN就能有效融合多模态信息，关键在于融合后的解码器设计（GPT-2自回归解码）。这提示我们在设计多模态客流预测模型时，应重视跨模态交互和解码策略。

5. **事件类型差异化处理**：不同事件对目标的驱动力差异很大。在实际系统中，应对不同类型的事件（节假日vs天气vs突发事件）建立差异化的特征工程和权重机制，而非一视同仁。

6. **高频时序预测的工程实践**：预测窗口设为35/70/140步（对应半天/一天/两天），这种多尺度评估方式值得在本项目中采用，以验证模型在不同预测horizon下的表现。

# ST13: Seeing the Unseen: Learning Basis Confounder Representations for Robust Traffic Prediction

## 基本信息

- **会议/期刊**: KDD 2025
- **作者**: Jiahao Ji, Wentao Zhang, Jingyuan Wang (Beihang University), Chao Huang (University of Hong Kong)
- **关键词**: 交通预测, 混杂因素, 因果推断, 分布偏移, 自监督学习

## 研究问题与动机

交通预测的核心是建立历史交通数据 $X$ 与未来交通状态 $Y$ 之间的关系。然而 $X \to Y$ 的关系经常受到外部混杂因素（天气、事故、节假日等）的干扰——这些因素同时影响 $X$ 和 $Y$。

**现有方法的局限性**：
- 前门/后门调整方法依赖预定义的离散混杂因素值，无法处理连续或未定义的混杂因素
- 现实场景中混杂因素往往不可完全观测，难以穷举

**核心思想**：不直接枚举天气、节假日等具体混杂因素，而是学习一个"基础混杂因素库"（Base Confounder Bank），任意混杂因素可表示为基础向量的线性组合。

## 核心贡献

1. 提出 STEVE（Spatial-Temporal sElf-superVised confoundEr learning）模型
2. 设计基础混杂因素库机制，用线性组合表示任意连续/未定义混杂因素
3. 引入自监督辅助任务（空间位置分类、时间索引识别、交通负荷预测）增强混杂因素表示
4. 通过对抗解耦（GRL）+ 互信息最小化（CLUB）实现混杂因素与不变表示的分离

## 方法概述

### 整体架构

```
历史交通流量 X_t + 交通图 A
        ↓
  双路时空编码器 TSRL
        ↓
  Z_t (变化表示)          H_t (不变表示)
        ↓                      ↓
  Confounder Bank         GRL + 对抗辅助任务
  + Cross-Attention       + 互信息最小化
        ↓                      ↓
  C_t (混杂因素表示)     H_t (去混杂表示)
        ↓                      ↓
  混杂相关预测 Ŷ_c        混杂无关预测 Ŷ_i
        ↓                      ↓
     异质性感知融合 → 最终预测 Ŷ_{t+1}
```

### 关键模块

#### 1. 基础混杂因素库（Base Confounder Bank）

- 维护可学习的基础向量库 $B = \{b^{(1)}, ..., b^{(K)}\}$
- 用动量更新机制维护：$B_{new} = \gamma B_{old} + (1-\gamma) \tilde{B}$
- 通过 Cross-Attention 从库中加权聚合：$C_t = \sum_{k=1}^{K} \alpha^{(k)} b^{(k)}$

#### 2. 自监督辅助任务（COSSL）

| 辅助任务 | 目标 | 标签来源 |
| :--- | :--- | :--- |
| 空间位置分类 | 让 $C$ 感知区域环境差异 | 节点 ID（one-hot） |
| 时间索引识别 | 让 $C$ 感知时间分布变化 | 48 类时间槽（区分工作日/节假日）|
| 交通负荷预测 | 让 $C$ 包含交通语义 | 历史最大流量近似负载容量 |

#### 3. 混杂因素解耦

**对抗解耦**：对不变表示 $H$ 使用 Gradient Reversal Layer (GRL)，使 $H$ 无法预测时间/空间/负荷等混杂因素。前向传播时 $GRL(H) = H$，反向传播时梯度反转 $\frac{\partial GRL(H)}{\partial H} = -\lambda I$。

**互信息最小化**：使用 CLUB（Contrastive Log-ratio Upper Bound）估计并最小化 $I(H; C)$，从统计依赖角度降低耦合。采用两阶段优化——先训练 MI 估计器（detach），再用 MI 上界约束主模型。

#### 4. 异质性感知融合

考虑混杂因素对不同区域/特征的影响不同：
$$\Lambda = \text{Sigmoid}(C_t W_c)$$
$$\hat{Y}_{t+1} = \text{Fusion}(\hat{Y}^{(c)}_{t+1}, \hat{Y}^{(i)}_{t+1}, \Lambda)$$

### 总损失函数

$$\mathcal{L} = \lambda_p \mathcal{L}_{pred} + \lambda_c \mathcal{L}_{C}^{conf} + \lambda_h \mathcal{L}_{H}^{adv} + 0.1 \mathcal{L}_{MI}$$

- $\mathcal{L}_{pred}$：预测损失
- $\mathcal{L}_{C}^{conf}$：混杂表示正向监督（variant_loss）
- $\mathcal{L}_{H}^{adv}$：不变表示对抗监督（invariant_loss + GRL）
- $\mathcal{L}_{MI}$：互信息最小化（CLUB）

### 选入 baseline 的方法详细分析

#### EX03: EVL — Modeling Extreme Events in Time Series Prediction (KDD 2019) ⭐⭐⭐⭐⭐

**经典奠基性工作**，首次系统研究深度学习在极端事件时序预测中的失败原因。

- **核心发现**：
  - 欠拟合：MSE 等价于高斯核密度估计，尾部指数衰减，无法恢复真实的慢衰减厚尾分布
  - 过拟合：人为增加极端样本权重会压缩正常区域估计，导致中段预测失准
- **核心方法**：
  - **Extreme Value Loss (EVL)**：基于极值理论的损失函数，用 BCE 形式预测是否为极值点，加入 EVT 尾部权重 `(1-u/γ)^γ`，γ=3 控制尾部厚度
  - **Memory Network**：存储历史极端事件模式，通过注意力机制融合记忆与当前预测
- **N-independent 分析**：EVL 是损失函数级别的增强，Memory 存储全局极端模式（不绑定特定节点），可应用于任意 per-series 模型 → **完全 N-independent**
- **代码**：github.com/HuiqunHuang/EVL ✓ (Python, 356KB)

#### EX05: EALGAP — Extreme-Aware Local-Global Attention (ICDE 2023) ⭐⭐⭐⭐⭐

**直接使用 NYC/CHI 自行车和出租车数据**，与本项目数据场景高度匹配。

- **核心方法**：
  - 将流量序列解耦为 **全局趋势 + 局部异常**
  - **全局趋势建模**：将所有流量数据拟合指数分布，利用概率密度生成 Q/K/V → Self-Attention → 全局趋势序列 → FC 预测
  - **局部极端度建模**：基于同时间段（相同 weekday/weekend + 相同时段）历史统计均值/方差，计算 z-score 偏离度 → GRU 预测极端程度
  - **最终预测**：全局趋势 + 极端程度 → ReLU → 输出
- **评测设计（极重要参考）**：每个数据集构建 3 类 test 集：①全正常 ②含极端天气 ③含节假日
- **N-independent 分析**：SA、GRU、FC 均为共享权重，极端度从同时段历史数据统计（非学习参数），无图结构 → **N-independent**
- **代码**：github.com/HuiqunHuang/EALGAP ✓ (Python, 2.5MB)

#### EX08: DAN — Distance-weighted Auto-regularized Network (AAAI 2024) ⭐⭐⭐⭐

**提出远/近极性分解的优雅设计**，将极端值预测拆解为两个通道。

- **核心方法**：
  - 将预测目标分解为 **far (远离正常值)** 和 **near (靠近正常值)** 两个极性
  - **RepGen**：双通道编解码，分别生成 y_far 和 y_near；同时预测外部指示器 y_i
  - **RepMerg**：融合 far 通道隐变量 + 指示器 → 增强 far 预测 → 与 near 拼接 → FC 最终输出
  - **距离加权损失**：w_f = (tanh(y))², w_n = (1-|tanh(y)|)²，正则化到均值 0 后按距离自动加权
  - **Kruskal-Wallis 采样**：重加权不平衡极端数据
- **N-independent 分析**：per-series 双通道处理，无图结构，全部共享权重 → **N-independent**
- **代码**：github.com/davidanastasiu/dan ✓ (Python, 247KB)
- **注意**：原始应用为水文径流预测，但距离加权极性分解技术是通用的极端值处理方法

#### EX13: ST-SSDL — Self-Supervised Deviation Learning (NeurIPS 2025) ⭐⭐⭐⭐⭐

**最新顶会工作**，显式建模当前数据与历史模式的"偏差"，与异常预测高度相关。

- **核心方法**：
  - **Historical Anchoring**：将每个输入锚定到其历史均值（数据计算，非学习参数），提取偏差信号
  - **Learnable Prototypes**：可学习原型离散化潜在空间，每个原型代表一种典型时空模式（shared, N-independent）
  - **Contrastive Loss**：增强不同原型间的判别性，防止模式坍缩
  - **Deviation Loss**：正则化输入表示与对应原型间的距离一致性，量化偏差程度
  - 联合优化：prediction loss + contrastive loss + deviation loss
- **N-independent 分析**：
  - 原型是全局共享的（不绑定特定节点）→ N-independent ✓
  - 历史均值从数据统计（非学习参数）→ N-independent ✓
  - 偏差/对比损失仅依赖表示空间距离 → N-independent ✓
  - 原始论文可能使用 STGNN backbone，适配时可替换为 per-node backbone
- **与异常预测的关联**：偏差学习本质上就是量化"当前模式与典型模式的差异程度"，这正是异常检测/预测的核心问题。高偏差 = 异常时段，低偏差 = 正常时段。
